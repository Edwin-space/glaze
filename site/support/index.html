지원

문제가 생기면 GitHub Issues에 남겨 주세요. macOS 버전, 앱 버전(글레이즈 → 글레이즈에 관하여), 무슨 일이 있었는지 적어 주시면 빨리 확인할 수 있습니다. NAS 주소나 비밀번호는 적지 마세요.

자주 묻는 질문

어떤 파일을 재생할 수 있나요?

MKV, MP4, MOV, AVI, WebM, M4V 영상과 SRT, VTT, SMI, ASS, SSA 자막을 열 수 있습니다. Finder에서 파일을 끌어다 놓거나 “파일 → 영상 열기…”(⌘O)를 사용하세요.

NAS는 어떻게 연결하나요?

설정 → 네트워크에서 WebDAV 주소를 추가하세요. 시놀로지는 “WebDAV Server” 패키지를 켜면 연결할 수 있습니다. 같은 네트워크의 DLNA/UPnP 미디어 서버는 네트워크 미디어 화면에서 자동으로 찾습니다.

HTTPS로 연결할 때 인증서 오류가 나요.

인증서가 my-nas.synology.me 같은 이름으로 발급되었는데 IP 주소로 접속하면 생기는 오류입니다. 글레이즈가 인증서에 적힌 이름을 알려주면 그 이름으로 주소를 바꾸세요. 자체 서명 인증서라면 지문을 확인한 뒤 신뢰할 수 있습니다.

자막 생성은 인터넷이 필요한가요?

처음 한 번 음성 인식 모델과 번역 언어 자료를 내려받을 때만 필요합니다. 그 뒤로는 영상과 음성이 맥 밖으로 나가지 않고 기기 안에서 처리됩니다.

작품 정보(포스터, 줄거리)가 안 나와요.

작품 정보는 TMDB에서 가져오며 본인의 TMDB API 키가 필요합니다. themoviedb.org에서 키를 발급받아 설정 → 작품 정보에 입력하세요. 잘못 찾은 작품은 정보 패널에서 다시 검색해 고칠 수 있습니다.

키보드 단축키를 바꾸고 싶어요.

설정 → 키보드에서 동작마다 원하는 키를 지정할 수 있습니다. 기본값은 스페이스 재생/일시정지, ←/→ 10초 이동, ↑/↓ 음량, ⌘←/⌘→ 이전/다음 영상입니다.

시스템 요구 사항은 무엇인가요?

macOS 26 이상이 필요합니다.

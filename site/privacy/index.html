개인정보 처리방침

시행일: 2026년 11월 9일 · 대상: 글레이즈 macOS · iOS · iPadOS · tvOS 앱

글레이즈는 이용자가 가진 영상을 재생하는 앱입니다. 개발자는 이용자에 관한 어떤 정보도 자동으로 수집하거나 전송받지 않습니다. 이용자가 직접 공유한 진단 파일은 문제 해결에 사용합니다.

수집하지 않는 것

계정을 만들지 않으며 이름, 이메일, 전화번호를 묻지 않습니다. 사용 기록을 수집하지 않고 분석 도구나 광고 SDK를 넣지 않았습니다. 개발자가 운영하는 서버가 없으므로 이용자가 개발자에게 자동으로 보내는 정보도 없습니다.

선택적 진단 기록

설정에서 켜면 앱 동작, 요청 소요 시간, 재생 상태와 오류 발생을 기기에만 기록합니다. 최대 15MB·7일간 보관하며 언제든 끄거나 삭제할 수 있습니다. 로그는 백업에서 제외됩니다. 주소, 인증 정보, 파일명, 자막·번역 본문은 기록하지 않습니다. 자료 식별에는 설치별 임의 키로 변환한 값을 사용합니다. 앱·OS 버전과 발생 시각이 보고서에 포함됩니다.

자동 업로드는 없습니다. 이용자가 공유 메뉴에서 선택한 대상에게만 진단 파일을 전달합니다. 개발자에게 전달한 파일은 해당 문제 해결에만 사용하고, 해결 후 30일 이내 삭제합니다. 진단 파일을 공개 GitHub 이슈에 첨부하지 마세요.

기기에만 저장되는 것

  • 영상을 어디까지 보았는지, 다 본 영상인지
  • 자막 언어, 자막 크기, 재생 속도, 키보드 단축키 같은 설정
  • 이용자가 직접 입력한 NAS 주소와 로그인 정보, TMDB API 키
  • 표지와 포스터 이미지 캐시(설정에서 지울 수 있습니다)

이 정보는 기기에 저장됩니다. NAS 비밀번호는 시스템 키체인에 저장됩니다. 키체인 항목은 앱을 삭제해도 남을 수 있으므로 앱 삭제만으로 모든 저장 정보가 삭제된다고 보장하지 않습니다.

이용자의 지시로 외부와 통신하는 경우

  • 이용자의 NAS·미디어 서버 — 이용자가 입력하거나 고른 서버에만 연결합니다. 같은 네트워크의 DLNA 서버를 찾을 때 로컬 네트워크를 사용합니다.
  • TMDB(themoviedb.org) — 작품 정보를 찾을 때 영상 파일의 제목을 보냅니다. 이용자를 식별할 수 있는 정보는 보내지 않습니다. 이용자가 TMDB API 키를 직접 입력했을 때만 동작합니다. 이 제품은 TMDB API를 사용하지만 TMDB가 보증하거나 인증하지 않았습니다.
  • 음성 인식 모델(Hugging Face) — 맥에서 자막 생성을 처음 사용할 때 음성 인식 모델 파일을 Hugging Face에서 내려받습니다. 이 요청에는 영상, 음성, 이용자 정보가 들어가지 않습니다. 다른 웹 요청처럼 Hugging Face가 접속 IP 주소를 볼 수는 있습니다.
  • 번역 언어 자료(Apple) — 자막 번역은 macOS의 번역 기능을 씁니다. 필요한 언어 자료는 macOS가 Apple에서 내려받으며, Apple의 개인정보 처리방침을 따릅니다.

음성 인식과 번역은 기기 안에서 이루어집니다. 영상과 음성은 기기 밖으로 전송되지 않습니다.

어린이

이 앱은 어린이를 대상으로 하지 않으며, 어린이에 관한 정보를 수집하지 않습니다.

변경

이 방침이 바뀌면 이 페이지를 고치고 시행일을 새로 적습니다.

Privacy Policy

Effective 9 November 2026 · Glaze for macOS, iOS, iPadOS and tvOS

Glaze plays video you already have. The developer does not automatically collect information about you and receives diagnostic reports only when you choose to share them.

What is not collected

There is no account and no request for your name, email or phone number. There is no analytics or advertising SDK. The developer runs no data collection server and the app does not automatically transmit diagnostic records.

What stays on your device

  • how far into a video you got, and which videos you have finished
  • settings such as subtitle language, subtitle size, playback speed and keyboard shortcuts
  • server addresses and credentials, and the TMDB API key, that you entered yourself
  • a cache of cover and poster images, which you can clear in Settings

These are stored on the device. NAS passwords are held in the system keychain. Keychain items can remain after uninstalling the app; uninstalling alone does not guarantee removal of all stored information.

Optional diagnostics

When enabled in Settings, technical events, request durations, playback states and errors stay on the device for up to 7 days, capped at 15 MB and excluded from backups. You can disable recording or delete the records. Addresses, credentials, filenames, subtitle text and translations are excluded. Resource references use an installation-local keyed hash. Reports contain the app and OS version and event times.

There is no automatic upload. You choose a recipient through the share menu. Reports you send to the developer are used only to resolve that issue and deleted within 30 days after resolution. Do not attach diagnostic reports to public GitHub issues.

When the app talks to something else, at your instruction

  • Your own NAS or media server — only a server you entered or chose. Finding DLNA servers uses your local network.
  • TMDB (themoviedb.org) — looking up film information sends the title of the file and nothing that identifies you. It runs only if you entered your own TMDB API key. This product uses the TMDB API but is not endorsed or certified by TMDB.
  • Speech recognition model (Hugging Face) — the first time you generate subtitles on the Mac, the speech model files are downloaded from Hugging Face. The request contains no video, audio or information about you. As with any web request, Hugging Face can see the IP address it came from.
  • Translation languages (Apple) — subtitle translation uses macOS's built-in Translation. macOS downloads any language it needs from Apple, under Apple's privacy policy.

Speech recognition and translation run on the device. No video or audio leaves it.

Children

The app is not directed at children and collects nothing about them.

Changes

If this policy changes, the revised version appears on this page with a new date.

Support

Report issues through GitHub Issues. Include your OS and app version and what happened. Keep server addresses, passwords and diagnostic reports out of public issues.

Frequently asked questions

Which files can I play?

Open MKV, MP4, MOV, AVI, WebM and M4V video, and SRT, VTT, SMI, ASS and SSA subtitle files. Drag files from Finder or use File → Open Video (⌘O).

How do I connect a NAS?

Use Settings → Network → Synology to sign in with your DSM address and account. A separate WebDAV Server package is not required for DSM access. For other WebDAV servers, add the server address and credentials. DLNA/UPnP is a separate connection method.

Why does HTTPS report a certificate error?

If a certificate is issued to a hostname such as my-nas.synology.me, connecting by IP can fail. Use the hostname on the certificate. For a self-signed certificate, verify its fingerprint before trusting it.

Does subtitle generation require internet?

Apple Silicon Mac downloads the speech model and translation language resources for first use. Speech recognition and translation then run on the device; video and audio are not sent to the developer.

Why are posters and film information missing?

Film information comes from TMDB and requires your own TMDB API key. Enter it in Settings → Film Information. You can search again from the information panel to correct a match.

Can I change keyboard shortcuts?

Use Settings → Keyboard. Defaults include Space for play/pause, Left/Right for ten-second seeking, Up/Down for volume and ⌘Left/⌘Right for previous/next video.

What are the Mac requirements?

AI subtitle generation and translation require Apple Silicon and macOS 26 or later. Download the speech model and language resources for first use. Availability depends on the engine and language pair.

Can English audio produce English subtitles?

Yes. Speech recognition creates subtitles in the spoken language. English captions can help you study the original words. Translation is a separate step using your selected language, and is not limited to Korean.

Synology DSM or WebDAV?

DSM connects directly to Synology file services using the DSM account, including a requested two-factor code. WebDAV uses a separately enabled service, address and access permissions. HTTPS is recommended.

What if a DLNA server is not discovered?

Discovery depends on the local network and multicast permissions. Current iPhone and iPad discovery has limitations. Apple TV can add a server by address; compatibility is not guaranteed for every server. Use Synology DSM or WebDAV on iPhone and iPad.

Can I connect using SMB?

On Mac, mount the SMB share in Finder → Go → Connect to Server (⌘K), then open the files in Glaze. This is not direct SMB sign-in inside the iPhone, iPad or Apple TV app.

How do I send a connection to Apple TV?

On the same network, display the receive-connection QR code on Apple TV. Long-press a saved server on iPhone, choose Send to TV, and scan it. This sends supported Synology or WebDAV connection details, not videos, subtitles or playback positions.

How do I watch on the subway?

Copy the video and subtitle files into Glaze on iPhone or iPad before leaving, using Files import or Finder file sharing. Keep the files in the same folder for offline viewing. This does not automatically connect your home NAS while travelling.

Which books are supported?

EPUB, PDF and CBZ, ZIP, 7z and CB7 comics. Imported books keep their reading position on that device. CBR and automatic cross-device reading-position sync are not supported.

Can Apple TV use subtitles prepared on Mac?

Keep the video and subtitles in the same accessible NAS folder, and connect that source on Apple TV. Saving beside the video requires folder access and write permission on Mac. Subtitles stored only inside the Mac app are not directly available elsewhere. Playback positions are stored per device.

Is the website demo running AI?

No. The interactive walkthrough uses a prepared original sample video and prepared example subtitles. Playback, seeking and subtitle selection work in your browser. Recognition timing is illustrative; the Apple Silicon Mac app performs the actual AI work.

# 글레이즈 · Glaze

나의 영상과 책을 위한 미디어 플레이어입니다. / A player for your own videos and books.

[한국어 홈페이지](https://edwin-space.github.io/glaze/) · [English](https://edwin-space.github.io/glaze/en/)

## 출시 계획 / Release roadmap

1. **iOS · iPadOS — App Store 심사 중 / in App Store review**: 영상·자막 감상과 독서.
2. **macOS — 다음 출시 / next**: Apple Silicon 온디바이스 음성 인식과 자막 번역.
3. **Apple TV — Mac 이후 / after Mac**: 거실의 큰 화면에서 개인 라이브러리 감상.

Windows GPU 기반 자막 처리와 Android 서비스는 향후 계획이며, 지원 범위와 일정은 아직 확정되지 않았습니다. / Windows GPU subtitle processing and Android services are future plans; scope and dates are not yet announced.

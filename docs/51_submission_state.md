## 1. 개발자 센터 (developer.apple.com)

### 멀티캐스트 권한 — 유일한 항목이고, 안 받아도 된다

```
com.apple.developer.networking.multicast
```

DLNA 자동 발견은 `239.255.255.250`으로 외치는 SSDP를 쓰는데, iOS와 tvOS에서는 이
권한이 있어야 한다. **애플이 신청을 받아 심사해서 내주는 특별 권한**이라 서식을
내고 기다려야 한다.

**지금 빌드에는 이 권한이 없다.** 확인한 사실: iOS·tvOS 타깃에는 entitlements 파일
자체가 없다(맥만 `Packaging/Glaze.entitlements`를 쓴다).

그래서 선택지는 둘이다.

| 선택 | 결과 |
|---|---|
| **신청하지 않고 출시** | DLNA 서버를 **주소로 직접 추가**해야 한다. 애플TV는 이미 그렇게 만들어 뒀다(`docs/47`). WebDAV·시놀로지는 영향 없음 |
| 신청하고 기다림 | 자동 발견이 동작한다. 승인까지 기간을 알 수 없고, 승인 뒤 빌드를 다시 올려야 한다 |

**권하는 쪽: 신청하지 않고 출시한다.** 지금 구조로도 서버를 쓸 수 있고, 자동 발견은
나중에 권한이 나오면 더하면 된다. 출시를 기약 없이 미룰 이유가 없다.

> 신청하려면: Account → Certificates, IDs & Profiles → Identifiers → `com.edwin.glaze`
> → **Additional Capabilities** → Multicast Networking → 신청 서식 작성.

### 그 밖에 개발자 센터에서 할 일 — 없다

확인한 것:
- 인증서·프로비저닝은 이미 동작한다(자동 서명, Apple Distribution으로 빌드 14 업로드됨)
- 백그라운드 오디오, 카메라, 로컬 네트워크, 파일 공유는 **전부 Info.plist 항목**이지
  개발자 센터에서 켜는 기능이 아니다. 이미 다 들어 있다
- 테스트 기기 등록은 끝났다(아이폰 17 Pro, 아이패드 미니)

## 2. 지금 막고 있는 것

### (1) 홈페이지 — 계정 소유자

네 주소 전부 **404**다. 오늘 확인했다.

```
https://edwin-space.github.io/glaze/           404
https://edwin-space.github.io/glaze/privacy/   404
https://edwin-space.github.io/glaze/terms/     404
https://edwin-space.github.io/glaze/support/   404
```

파일과 배포 워크플로는 저장소에 있다(`site/`, `.github/workflows/pages.yml`).
**저장소 설정에서 Pages를 켜는 것만 남았다** — `docs/45` 0절.

처리방침 URL과 지원 URL은 App Store Connect **필수 입력**이다. 이것이 1번 블로커다.

### (2) 빌드 15가 필요하다

빌드 14 이후 들어간 것 — 전부 아직 심사용 빌드에 **없다**:

- 재생 막대를 끌 때 2배속이 걸리던 문제
- 손동작 이동이 컨트롤바를 통째로 불러오던 문제 + 컨트롤 없이 끌 때의 표시
- 다음 화로 넘겨도 미리보기가 첫 영화를 가리키던 문제
- 매 틱마다 돌던 트랙 열거·위치 저장·잠금화면 갱신
- 재생바 포인터가 이전 영화 시계를 보여주던 문제
- 섬네일 연결 버퍼

### (3) 애플TV 스크린샷

`Marketing/ios/`에 아이폰 6.9형과 아이패드 13형만 있다. tvOS는 **1920×1080**이 따로
필요하다. 아이콘(`AppIcon.brandassets`)은 있다 — 빌드 14가 검증을 통과했으므로.

### (4) 네트워크 버그 2건

- 이어볼 지점이 있는 네트워크 영상이 열리지 않음 (`docs/50` 부록 3·5) — **원인 미파악**
- 다음 화 10번쯤 넘기면 화면이 안 나옴 — **재현 테스트를 아직 못 돌림**

**이것이 출시를 막는지는 결정할 일이다.** 심사를 통과하지 못할 종류는 아니지만,
NAS로 보는 사람에게는 눈에 띄는 결함이다.

## 3. App Store Connect — 계정 소유자

`docs/45`의 절차가 그대로 유효하다. 플랫폼별로 따로 해야 하는 것과 앱 전체에 한 번만
하는 것을 구분해 둔다.

| 항목 | 범위 | 비고 |
|---|---|---|
| 처리방침 URL | 앱 전체 | Pages를 켠 뒤 |
| 앱 개인정보 보호 (게시) | 앱 전체 | `데이터를 수집하지 않음` |
| 콘텐츠 권한 | 앱 전체 | **예** — TMDB 포스터·줄거리 |
| 연령 등급 | 앱 전체 | 예상 4+ |
| 빌드 연결 | **플랫폼마다** | macOS / iOS / tvOS 각각 |
| 스크린샷 | **플랫폼마다** | 아이폰·아이패드 준비됨, tvOS 없음 |
| 지원·마케팅 URL | **플랫폼마다** | |
| 심사 메모 | **플랫폼마다** | 맥 메모는 `docs/45` 7절 |
| 수동 출시 선택 | **플랫폼마다** | |

> 심사 메모에 **NAS 없이 테스트하는 방법**을 반드시 적는다. 심사자에게는 서버가
> 없고, 네트워크 기능이 동작하지 않는 것처럼 보이면 거절 사유가 된다.

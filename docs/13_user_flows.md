# 사용자 플로우

작성일: 2026-06-18  
프로젝트명: 글레이즈 / Glaze

## 문서 목적

이 문서는 글레이즈의 핵심 사용자 흐름을 정의한다. 기능 구현 전에 사용자의 행동, 앱의 판단, 표시할 안내, 예외 처리를 정리해 잘못된 흐름을 조기에 발견하고 수정하기 위한 문서다.

이 문서는 이후 사용자 가이드, FAQ, 온보딩, 도움말 문서의 기반이 된다.

## 플로우 설계 원칙

- 사용자가 요청하지 않은 AI 작업은 시작하지 않는다.
- 재생 흐름을 먼저 보장하고, 자막 생성은 제안으로 제공한다.
- 자막이 없다는 사실은 숨기지 않지만 감상을 방해하지 않는다.
- 저장 위치 선택은 자막 생성 요청 시점에 묻는다.
- 시스템 언어와 영상 언어를 고려해 제안을 다르게 한다.
- 오류는 조용히 실패하지 않고 다음 행동을 제시한다.

## Flow 1. 첫 실행

### 목표

사용자가 앱을 처음 열었을 때 무엇을 할 수 있는지 즉시 이해한다.

### 흐름

1. 앱 실행
2. 시스템 언어 확인
3. 한국어/영어 UI 적용, 미지원 언어는 영어 fallback
4. 빈 플레이어 화면 표시
5. "영상 열기" 액션 제공

### 표시 텍스트

- 영상을 열어 자막 준비를 시작하세요
- 로컬 영상부터 시작합니다. 자막이 없으면 글레이즈가 준비를 도와드립니다.

### 실패/예외

- localization 로딩 실패 시 영어 fallback

## Flow 2. 로컬 영상 열기

### 목표

사용자가 로컬 파일을 선택하고 바로 재생한다.

### 흐름

1. 사용자가 "영상 열기" 선택 또는 플레이어 내부로 영상/폴더 드래그앤드롭
2. 파일/폴더 선택 패널 표시 또는 드롭 URL 수신
3. 사용자가 영상 파일 또는 폴더 선택
4. 앱이 선택한 영상 또는 폴더의 영상 파일을 재생목록으로 구성
5. 앱이 AVPlayerItem 생성
6. 영상 재생 시작
7. 같은 폴더의 sidecar 자막 파일 감지
8. 앱이 미디어 컨테이너, AVKit 직접 재생 가능 여부, 트랙/코덱 인식 상태를 확인
9. 자막 상태 strip 업데이트

### 감지 대상

- `movie.srt`
- `movie.vtt`
- `movie.smi`
- `movie.ko.srt`
- `movie.ko.vtt`
- `movie.ko.smi`
- `movie.en.srt`
- `movie.en.vtt`
- `movie.en.smi`
- `movie.original.srt`
- `movie.original.vtt`
- `movie.original.smi`

### 실패/예외

- 파일을 열 수 없음: 재생할 수 없는 파일이라는 메시지 표시
- AVKit 미지원 포맷: 미디어 정보 패널과 FFmpeg 검증 후보로 기록
- 재생 아이템 실패: 현재 재생할 수 없다는 메시지를 표시하고 미디어 정보 패널에서 원인 확인
- 파일 접근 권한 없음: 권한 안내

### 현재 구현 상태

- 영상 파일/폴더 드래그앤드롭으로 재생 시작
- 선택한 영상과 같은 폴더의 추가 영상 자동 재생목록 구성
- 재생목록 패널에서 영상 전환
- 이전/다음 아이콘으로 재생목록 항목 이동
- 현재 영상이 끝나면 다음 재생목록 항목 자동 재생
- macOS 드래그앤드롭 직후 SwiftUI `VideoPlayer` 재구성 크래시를 피하기 위해 `AVPlayerView` 기반 재생 표면으로 전환
- `AVPlayerItem` 준비 완료 후 재생을 시작하고, 실패/대기 상태를 사용자에게 표시
- 앱 내부 미디어 정보 패널에서 컨테이너, macOS 직접 재생 가능 여부, 인식된 트랙/코덱을 표시
- MKV/고해상도/다중 트랙 파일의 실패 유형을 제품 판단 데이터로 남길 수 있는 기반 구현

## Flow 3. 자막 파일이 감지된 영상

### 목표

사용자가 별도 행동 없이 기존 자막 존재 여부를 알 수 있다.

### 흐름

1. 영상 파일 열기
2. sidecar 자막 감지
3. 한국어 자막이면 "한국어 자막 감지됨"
4. 원어/기타 자막이면 "자막 감지됨"
5. 앱은 우선순위에 따라 한국어, 원어, 기타 자막 순으로 자동 선택
6. 자막 패널에는 감지된 파일 목록과 현재 선택된 파일을 표시
7. 사용자는 자막 패널에서 다른 자막 파일로 전환할 수 있음
8. 사용자는 상태 strip 또는 자막 패널에서 자막 표시/숨김을 전환할 수 있음

### 현재 구현 상태

- sidecar 감지와 상태 표시 구현
- 수동으로 불러온 자막 파일도 상태에 반영
- 감지된 SRT/VTT/SMI 자막 파일을 기본 파싱해 영상 위에 표시
- 여러 자막 파일 중 선택/전환 UI 구현
- 자막 표시/숨김 전환 구현
- SMI는 UTF 계열, EUC-KR, CP949 계열, ISO Latin 1 순서로 읽기 시도
- SMI의 head/style/script 노이즈 제거 및 한국어 class 우선 표시 구현

### 남은 개선 필요

- SMI의 폰트, 색상, 위치 스타일을 원본처럼 재현하는 고급 스타일 엔진
- 자막 목록 검색, 정렬, 언어 필터 같은 대량 라이브러리용 편의 기능

## Flow 3A. AI 미디어 어시스턴트

### 목표

사용자가 영상 파일을 추가했을 때, 글레이즈가 자막뿐 아니라 작품 정보와 라이브러리 정리 상태까지 준비할 수 있음을 자연스럽게 보여준다.

### 흐름

1. 영상 파일 또는 폴더 열기
2. 앱이 `MediaAsset` 생성
3. 파일명 기반 제목 후보 추출
4. 자막 준비 상태 확인
5. AI 미디어 버블 표시
6. 사용자가 AI 미디어 패널 열기
7. 앱이 작품 정보, 자막 준비 상태, 보관 위치를 표시
8. 사용자는 작품 정보 찾기, 자막 준비, 파일 정보 반영 흐름으로 진입할 수 있음

### 현재 구현 상태

- `MediaAsset` 기초 모델 추가
- AI 미디어 버블과 패널 추가
- 작품 정보 매칭, 자막 준비, 파일 정보 반영 액션 자리 표시
- 원본 파일 쓰기는 기본값이 아니라 명시적 액션으로 분리

### 남은 개선 필요

- TMDB/IMDb/TVDB 등 메타데이터 공급자 추상화
- 포스터/줄거리/시즌/에피소드 매칭 UI
- sidecar metadata 저장
- 원본 파일 태그 쓰기 전 백업/권한/컨테이너 호환성 검증

## Flow 4. 자막 파일이 없는 영상

### 목표

사용자가 영상 재생을 방해받지 않으면서 자막 생성 가능성을 알 수 있다.

### 흐름

1. 영상 파일 열기
2. sidecar 자막 없음
3. 상태 strip에 "생성 가능" 표시
4. 안내 문구 표시: "같은 이름의 자막을 찾지 못했습니다. 필요할 때 생성하거나 불러올 수 있습니다."
5. 사용자는 그냥 시청하거나 자막 패널을 열 수 있다.

### 중요한 원칙

저장 위치 선택 UI는 이 시점에 띄우지 않는다.

## Flow 5. 자막 생성 요청

### 목표

사용자가 명시적으로 요청했을 때만 AI 자막 생성 흐름을 시작한다.

### 흐름

1. 사용자가 "자막 생성" 선택
2. 앱이 자막 생성 옵션 패널 표시
3. 영상 언어: 자동 감지 또는 직접 선택
4. 출력: 원어, 한국어, 원문 + 한국어
5. 모델 모드: 빠른, 표준, 고정확도
6. 저장 위치 선택: 앱 내부 또는 영상 파일 옆
7. 사용자가 확인
8. 자막 생성 작업 시작

### 아직 미구현

- 실제 오디오 추출
- 음성 인식
- 번역
- 저장 위치 권한 처리
- 진행률 표시

## Flow 6. 시스템 언어 기반 자막 제안

### 목표

사용자 환경에 맞는 세심한 제안을 제공한다.

### 예시

시스템 언어가 한국어이고 영상 언어가 영어로 추정되며 한국어 자막이 없을 때:

1. 영상 재생 시작
2. 앱이 한국어 자막 없음 상태 확인
3. 방해가 적은 안내 표시
4. 선택지 제공:
   - 자막 생성
   - 그냥 시청
   - 자막 파일 불러오기

시스템 언어가 한국어이고 영상 언어도 한국어로 추정될 때:

- 자막 생성 제안을 최소화한다.

### 구현 시점

영상 언어 추정 기능이 필요하므로 MVP 초기에는 수동/간접 안내로 시작한다.

## Flow 7. 자막 파일 수동 불러오기

### 목표

자동 감지가 실패했거나 사용자가 별도 자막 파일을 갖고 있을 때 연결할 수 있다.

### 흐름

1. 사용자가 자막 패널 열기
2. "자막 파일 불러오기" 선택
3. SRT/VTT/SMI 파일 선택
4. 앱이 파일을 읽고 연결
5. 상태 strip 업데이트
6. 연결된 자막 파일은 자막 패널 목록에 추가
7. 사용자는 목록에서 자막 파일을 다시 선택해 전환 가능
8. 자막 파일을 연결하면 자막 표시 상태는 다시 켜짐

### 현재 구현 상태

- SRT/VTT/SMI 파일 선택 구현
- 선택한 자막 파일을 현재 영상의 자막 상태에 반영
- 선택한 자막 파일을 기본 파싱해 영상 위에 표시
- 지원하지 않는 형식, 읽기 실패, 표시 가능한 cue 없음 오류를 구분해 안내
- 읽기 실패 시 재생은 유지하고 자막 상태만 해제
- 자막 표시/숨김 전환 구현

### 남은 개선 필요

- App Sandbox 보안 범위, 파일 이동/삭제, 권한 오류를 더 세밀하게 구분

## Flow 8. 자막 생성 실패

### 목표

실패 원인을 숨기지 않고 사용자가 다음 행동을 선택할 수 있게 한다.

### 실패 유형

- 오디오 트랙 없음
- 지원하지 않는 파일
- 모델 없음
- 저장 권한 없음
- 디스크 공간 부족
- 앱 종료 또는 작업 중단

### 표시 원칙

- 실패 원인
- 사용자가 할 수 있는 다음 행동
- 다시 시도 가능 여부

## 다음 검토

- 자막 생성 파이프라인이 구현되면 Flow 5와 Flow 8을 상세화한다.
- 영상 언어 추정이 가능해지면 Flow 6을 세분화한다.

## 핵심 비교

| 구간 | Movist Pro | Submarine Player | Glaze 결정 |
|---|---|---|---|
| 재생 조작 | 영상 위에 작고 분산된 transport controls, 자막·오디오·동기화 접근이 빠름 | AI 준비 작업이 중심이고 일반 플레이어 조작은 상대적으로 약함 | 영상 위에는 시간축과 micro controls만 유지한다 |
| 기존 자막 | 내장·외부·온라인·생성 자막을 각각 켜고 끌 수 있고 트랙·싱크·표시 설정이 풍부함 | 같은 이름의 외부 SRT 자동 연결이 감사 시나리오에서 확인되지 않음 | 외부 자막과 내장 자막을 명시적으로 구분하고 현재 선택 상태를 먼저 보여준다 |
| AI 자막 | 일반 자막 설정 안에서 생성 자막도 하나의 소스로 다룸 | 전사 모델, 원본 언어, 번역 언어, 원문·번역 표시를 독립된 작업으로 명확히 분리함 | AI 생성은 기존 자막 선택·번역과 분리된 독립 섹션이며 명시적 실행만 허용한다 |
| 언어 교정 | 트랙과 자막 언어 선택을 플레이어 관례에 맞게 제공 | 원본/대상 언어 선택과 언어 팩 준비가 명확함 | 파일의 언어 태그가 틀려도 사용자가 현재 자막 언어를 바로잡고 번역 대상 언어를 별도로 저장한다 |
| 자막 스타일 | 크기·위치·스타일·동기화·TTS까지 상세함 | 크기·배경 농도·색·원문/번역 표시를 작업 화면과 플레이어 popover에서 제공 | 자주 바꾸는 언어·가시성은 Inspector, 전역 스타일은 설정 허브에 둔다 |
| 설정 구조 | macOS 네이티브 툴바에 폭넓은 플레이어 카테고리 | 전사·번역·자막·캐시를 작업 중심으로 분리 | `NavigationSplitView` 설정 허브와 현재 영상 Inspector의 역할을 분리한다 |

## 채택한 정보 구조

1. 자막 Inspector 첫 섹션은 현재 선택된 자막, 외부 파일, 영상 내장 트랙, 표시/숨김, 파일 불러오기만 다룬다.
2. 실제 cue가 준비된 경우에만 현재 자막 언어와 번역 대상 언어를 보여준다.
3. 번역은 기존 자막을 입력으로 사용하는 별도 섹션이다.
4. 음성을 분석해 새 자막을 만드는 기능은 `AI로 자막 만들기` 섹션으로 완전히 분리한다.
5. 모델·저장 위치·진행률은 AI 생성 섹션에만 둔다.

## 제품 판단

Movist의 장점은 일반 플레이어 기본기와 높은 조작 밀도이고, Submarine의 장점은 AI 전사·번역 작업의 명료한 분리다. Glaze는 둘을 그대로 합치지 않는다. 감상 중에는 Movist 수준의 조용한 플레이어를 유지하고, 자막 Inspector에서는 Submarine처럼 입력 자막·번역·새 AI 생성을 서로 다른 작업으로 구분하는 것이 기준이다.

판정이며 기능 전체·접근성·출시 적합 통과가 아니다.

## 1. Mac 시작 — 배치 양호

파일 열기와 네트워크 진입이 분리돼 있다. 960×660 창에서 제목·버튼의 잘림 없음.
키보드 전체 탐색과 대비 증가 상태는 별도 확인이 필요하다.

## 2. Mac 설정 6개 영역 — 부분 개선 필요

구조를 쓴다. 진단만 제목 없이 중앙에 배치되는 UI-01이 확인됐다. 아래 네트워크

## 3. Mac 재생·자막·정보 패널 — 배치 양호, 언어/정보 표기 개선 필요

같은 샘플이 실제로 재생되고 패널을 열어도 영상과 컨트롤이 창 안에 남는다.
자막 목록은 체크로 선택을 표현한다. 언어 코드·포맷명 중심 표기는 UI-02/06의 개선
대상이고, Matroska를 WEBM으로 표시하는 UI-06은 정보 오류다. 보조 설명/값의 대비는
현재 유리 배경을 포함해 추가 측정해야 한다. 일시정지 전환 후 검은 프레임 후보는
재실행·3초 대기·재생/정지에서 지속 재현되지 않아 확정 결함으로 분류하지 않았다.

## 4. iPhone 13 mini 실물 온보딩 — 배치 양호, 시작 버튼 대비 개선

실물 기기에서 시작 버튼이 안전 영역 안에 있고 설명 끝까지 스크롤된다.
UI-05: 흰 Start/앰버 배경의 표본 대비 약 2.37:1. 온보딩 이외 실제 기기 흐름까지
통과했다고 해석하지 않는다.

![iPhone 13 mini 온보딩 실물](09-mini-welcome-physical.png)

## 5. iPhone 설정: 한국어·영어·최대 확대 글자 — 부분 개선 필요

한국어 행 배치는 유지되며 확대 글자에서는 수직으로 재배치되고 스크롤된다.
영문 UI의 언어명만 한국어로 나오는 UI-02가 있다. 확대 검수는 캡처된 상단과 다음
스크롤 구간까지이며, 모든 설정의 모든 Dynamic Type 단계가 통과한 것은 아니다.

## 6. iPhone 진단 — 배치 양호

꺼진 기록 스위치, 로컬 보존/제외 정보, 보고서 준비와 삭제가 구분돼 있다.
이 캡처 검수에서는 기록을 켜거나 실제 데이터를 삭제하지 않았다. 보고서 내용의
개인정보 감사와 공유 시트 접근성은 별도 출시 게이트다.

![iPhone 진단](12-mini-diagnostics.png)

## 7. iPhone 네트워크·WebDAV 입력 — 진입/입력 설명 개선 필요

추가 버튼에서 소스 선택과 WebDAV 폼으로 이동하고 URL 입력까지 진행됐다.
UI-04: 빈 화면의 다음 행동은 우측 상단 +에만 의존한다. UI-03: 값 입력 후 필드명이
사라진다. URL 키보드는 맞고 세로 화면의 연결 버튼은 가리지 않는다. 예시 URL만
입력했으며 저장·인증·접속·연결 실패 복구를 검증한 것이 아니다.

![네트워크 빈 화면](13-mini-network-empty.png)
![WebDAV 주소 입력과 키보드](14-mini-webdav-input.png)

## 8. iPhone 로컬 재생·내장 자막·시간 조정 — 배치 양호, 언어/접근성 보완

2개 샘플 폴더에서 영상을 열고 이전/다음, 탐색, 재생, 자막 진입 컨트롤이 표시됐다.
세로/가로에서 상단 버튼 잘림은 재현되지 않았다. 긴 내장 트랙 목록 뒤에도 Delay,
크기, 오디오, 기본 언어를 스크롤해 찾을 수 있었다. UI-02와 Delay 버튼의 의미 있는
접근성 이름·터치 영역 검증이 남는다. 자막 파일 가져오기/실제 음성 전환은 별도다.

## 9. iPhone 최초 재생 제스처 안내 — 가로 화면 불량 / P1

세로에서는 설명과 완료 버튼이 표시된다. 가로에서는 제목과 완료 버튼이 화면 밖으로
나간다(UI-00). 이는 전체 화면 캡처이며 잘못된 앱 프레임 크롭은 제외했다. 키보드나
VoiceOver에서 버튼에 접근하더라도 시각적으로 보이지 않는 문제는 해결되지 않는다.

## 10. iPhone 서재 빈 상태 — 배치 양호 / 리더 미검수

한국어 설명과 지원 파일 유형이 표시된다. 이번에는 도서용 공개 검수 fixture를
준비하지 않아 PDF/EPUB/만화 리더·책갈피·페이지 조작은 미검수다. 빈 서재만으로
도서 기능 전체가 정상이라고 판정하지 않는다.

## 11. iPad 설정·가로 재생 — 배치 양호, 언어명 개선 필요

13형 iPad 시뮬레이터의 설정/재생/자막 시트 흐름이 실행됐고 가로 영상과 컨트롤은
화면 안에 남는다. UI-02는 동일하게 발생한다. 전체 폭 설정의 읽기 밀도는 개선
후보이나 겹침은 확인하지 못했다. 멀티태스킹·작은 창·실물 iPad는 미검수다.

## 12. Apple TV 온보딩·홈·설정 — 진입/리모컨 양호, 표기/대비 개선

실물 TV가 아닌 독립 1080p 시뮬레이터다. 리모컨으로 계속→기본 언어→소스 설정에
도달했고 홈에서 설정 탭도 열었다. 포커스와 기본값 체크는 구별된다. 빈 홈에 연결
CTA가 있다. UI-02, UI-05 개선 필요. 탭은 수평 스크롤돼 가장자리 항목이 일부
가려지지만 리모컨으로 설정에 도달했다. 과밀 여부는 한국어와 실물 TV에서 추가 확인.
서버 미발견은 이 네트워크 환경의 관찰이지 자동 발견 기능 전체의 실패 판정이 아니다.

## 13. 종단 흐름 — 미검수 / 출시 판정 불가

실제 NAS 연결/인증/탐색/즐겨찾기/이어보기/반복 전환, TMDB 결과 선택·저장,
AI 생성·번역 완료/취소/실패, 도서 리더, tvOS 재생·탐색·자막, Mac 배포 서명
Release 권한, 전 플랫폼 VoiceOver·대비 증가·투명도 줄이기·최소 지원 OS는
유효한 종단 캡처가 없다. 실제/전용 검수 서버·추가 fixture와 별도 시나리오가 필요하다.
기존 화면의 버튼 존재나 이전 문서로 대신 통과 처리하지 않았다.

## 14. UI-00–06 수정 후 증거

최초 검수 원본은 위에 보존한다. 아래는 수정본에서 직접 열어 확인한 증거이며
전체 기능/접근성 통과를 의미하지 않는다. 최초 안내는 최종 일반/접근성 분기 코드의
캡처다. 다른 패널은 해당 수정이 들어간 재검수 배치의 원본이며 이후 안내 전용 수정은
그 패널들을 바꾸지 않는다. 테스트 식별자/실행 경계는 [수정 후 보고](../../53_release_design_audit.md)에 기록한다.

### 최초 안내 · 일반 가로와 최대 글자 스크롤

일반 크기에서는 제목·완료 고정, 접근성 크기에서는 제목도 본문과 스크롤한다.
두 경우 모두 완료 버튼은 화면 안에 남고 실제 탭으로 안내를 끝냈다.

제목과 설명이 공통 설정 시작선을 따르고 기록/공유/삭제가 카드로 구분된다.
MKV 정보는 Matroska로 표시하며 정지 상태 영상도 유지된다. 회색/유리 표면의

# macOS Release 디자인 감사 — 2026-09-02

## 범위

- 대상: 서명된 macOS Release 빌드
- 사용자 목표: 로컬·네트워크 영상을 열고, 재생·자막·번역·미디어 정보·환경 설정을 막힘 없이 사용한다.
- 접근성 목표: 키보드와 VoiceOver가 주요 행동과 상태를 구분하고, 투명 표면 위 텍스트가 영상·브랜드 배경과 분리되어 읽힌다.
- 캡처: Computer Use로 현재 Release 앱을 직접 조작하고 각 상태를 저장했다.

## 감사 단계와 상태

1. **시작 화면 — 보완 필요**  
   ![시작 화면](01-launch.jpg)  
   구조는 단순하고 영상 열기·네트워크 미디어의 진입점이 한곳에 있다. 다만 두 버튼의 비활성처럼 보이는 낮은 대비 때문에 1차 행동이 즉시 드러나지 않았다.

2. **네트워크 미디어 — 보완 필요**  
   ![네트워크 미디어](02-network-browser.jpg)  
   Finder식 위치 사이드바와 상단 경로·보기 바의 구조는 적절하다. 자동 발견 실패가 원시 영문 시스템 오류로 노출돼 언어 일관성과 신뢰를 해쳤다.

3. **자막 설정 — 양호**  
   ![자막 설정](03-settings-subtitles.jpg)  
   실제 자막 미리보기와 컨트롤의 인과관계가 명확하다. 브랜드 배경이 카드와 보조 설명보다 강하고, 페이지 제목의 둥근 서체가 macOS 설정 문법과 어긋났다.

4. **번역 설정 — 양호**  
   ![번역 설정](04-settings-translation.jpg)  
   사용자가 요청하기 전 번역이 시작되지 않는다는 설명과 엔진·품질·출력 순서가 명확하다. 자막 설정과 비교해 정보 밀도가 크게 달라 빈 공간이 과도하지만 기능 혼란은 없다.

5. **네트워크 설정 — 양호**  
   ![네트워크 설정](05-settings-network.jpg)  
   자동 발견, WebDAV, SMB, FTP 지원 수준이 분리돼 있다. 작은 보조 문구와 하단 항목은 기본 창 높이에서 스크롤이 필요하며 배경 대비 보강이 필요했다.

6. **작품 정보 설정 — 양호**  
   ![작품 정보 설정](06-settings-metadata.jpg)  
   API 키가 선택 기능임을 설명하고 출처 링크를 제공한다. 카드 내부 설명이 길어 입력 필드보다 시선이 먼저 분산됐다.

7. **재생 화면 — 양호**  
   ![재생 화면](07-player.jpg)  
   영상 우선 원칙, 중앙 전송 버튼, 하단 타임라인, 우측 보조 조작의 계층이 명확하다. 모든 조작은 접근성 트리에 라벨이 있고 타임라인·음량은 adjustable control로 노출된다.

8. **자막 Inspector — 보완 필요**  
   ![자막 Inspector](08-subtitle-inspector.jpg)  
   기존 자막, 언어, 번역, AI 생성이 기능별로 분리돼 있다. 340pt 폭과 밝은 브랜드 배경 때문에 긴 설명·선택값의 대비가 약하고 마지막 AI 생성 영역이 잘린 듯 보였다.

9. **재생목록 Inspector — 양호**  
   ![재생목록 Inspector](09-playlist-inspector.jpg)  
   현재 재생 항목은 명확하지만 한 항목일 때 넓은 빈 공간이 생긴다. 빈 공간은 영상 재생을 방해하지 않아 구조적 결함으로 보지 않았다.

10. **미디어 정보 Inspector — 보완 필요**  
    ![미디어 정보 Inspector](10-media-info-inspector.jpg)  
    파일·작품 정보·트랙 순서는 적절하다. 영상 위 밝은 배경과 겹친 보조값, 긴 트랙 정보, 하단 잘림이 읽기 부담을 만들었다.

## 반영한 수정

- 시작 화면 1차·2차 버튼에 명시적인 흰색 레이블과 안정적인 최소 폭을 적용했다.
- 설정 페이지 제목을 macOS 시스템 `title2`로 통일하고 콘텐츠 폭·여백을 정규화했다.
- 브랜드 배경에 용도별 어두운 scrim 토큰을 추가해 설정 18%, 네트워크 12%, 재생 Inspector 36%로 분리했다.
- Inspector 기본 폭을 380pt로 넓히고 세 패널의 스크롤 하단 여백을 추가했다.
- DLNA/UPnP 오류는 짧은 한국어·영어 상태로 표시하고 원시 오류는 도움말에만 남겼다.

## 접근성 확인 범위

- 확인: 주요 버튼 이름, Inspector 탭 선택 상태, 자막 토글 상태, 슬라이더 adjustable action, 사이드바 선택 구조, 스크롤 컨테이너 존재.
- 미확인: VoiceOver 실제 발화 순서, Increase Contrast/Reduce Transparency 조합, 색각별 대비 수치, 200% 확대와 모든 영어 장문 상태. 스크린샷만으로 WCAG 또는 Apple 접근성 준수를 확정하지 않는다.

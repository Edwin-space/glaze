# 아이폰·아이패드 — 영상 정보 고치기와 목록 표시

작성일: 2026-10-06 · 대상: `Sources/GlazeiOS`, `Packages/GlazeCore`

빌드 13을 실기기에서 쓰고 나온 세 가지 중 두 가지를 다룬다. 영상 정보를 다시
찾는 기능을 **어디에서 하는지 알 수 없었던 문제**와, 새 파일 표시(NEW)의 위치다.

## 1. 영상 정보 다시 찾기 — 기능은 있었고, 입구가 없었다

### 확인한 것

로직은 이미 다 있었다.

| 하는 일 | 코드 |
|---|---|
| TMDB 검색 | `IOSMetadataModel.search(_:year:apiKey:languageCode:)` |
| 결과가 여러 개일 때 순위 | `MetadataMatchRanker.rank(_:against:)` — 파일 이름에서 읽은 제목·연도와 비교 |
| 이용자가 고르기 | `IOSMediaInfoView`의 결과 목록. 포스터·연도·원제·줄거리를 함께 보여준다 |
| 고른 뒤 확인 | 경고창에서 "바꾸기"를 눌러야 파일을 쓴다 |
| 저장 | `.nfo`와 `-poster.jpg`를 영상 옆에 |

즉 "다수의 데이터가 나올 때 선택권을 주는 핵심 로직"은 처음부터 있었다.
없었던 것은 **그 화면으로 가는 길**이다. 기기 안 폴더 목록에서 영상을 **길게 누르는**
것 하나뿐이었고, 네트워크(NAS) 영상에는 아예 없었다.

iOS에서 길게 누르기는 발견되지 않는 제스처다. 목록의 한 줄에 무언가를 하려는 사람은
먼저 **옆으로 미는** 쪽을 시도한다 — 메일과 메시지가 가르쳐 놓은 동작이다.

### 바꾼 것

- 기기 폴더: 영상 줄을 왼쪽으로 밀면 **영상 정보**가 나온다. 길게 누르기도 그대로 둔다
- 네트워크 폴더: 목록에서는 밀기와 길게 누르기, 타일(아이콘·갤러리) 보기에서는
  길게 누르기로 같은 화면이 열린다
- 네트워크 영상도 고친 정보를 **NAS에 저장**한다

### NAS에 쓰는 것 — 서버 종류에 따라 다르다

`NetworkFolderReader.sidecarDestination(forFilmAt:)`가 서버에 맞는 저장 위치를 돌려준다.

| 연결 | 저장 | 이유 |
|---|---|---|
| WebDAV | **된다** (`WebDAVSidecarDestination` → PUT) | 프로토콜에 쓰기가 있다 |
| DLNA/UPnP | 안 된다 | UPnP ContentDirectory에는 쓰기 동작이 없다. 목록일 뿐 파일 시스템이 아니다 |
| 시놀로지(DSM) | 안 된다 | FileStation 업로드 API는 탐색에 쓰는 API와 다르다. 아직 만들지 않았다 |

쓸 수 없는 서버에서는 **검색은 되고 저장만 막는다.** 화면 아래에 "이 서버에는 파일을
쓸 수 없습니다"라고 먼저 말하고, 결과를 고르는 버튼을 비활성화한다. 검색해서 고르고
확인까지 누른 뒤에 실패를 알리는 쪽이 더 나쁘다.

`IOSMetadataModel`은 이제 `videoURL` 대신 `baseName` + `SidecarDestination?`을 받는다.
저장할 곳이 없으면 `canSave`가 거짓이고, 화면이 그 사실을 먼저 보여준다.

## 2. NEW 표시 — 자리를 고정했다

전에는 제목 **옆에** 붙는 캡슐(`IOSNewBadge`)이었다. 제목 길이가 줄마다 다르므로
표시도 줄마다 다른 곳에 있었고, 긴 제목은 표시에 밀렸다.

목록(`IOSListRow`)에서는 **줄 맨 앞의 고정된 칸**에 7pt 호박색 점으로 바꿨다. 칸은
모든 줄에 항상 있고, 새 파일이 아니면 비어 있다. 메일과 팟캐스트가 안 읽은 줄을
표시하는 방식이다. 눈이 한 줄을 따라가지 않고 **왼쪽 한 줄기만** 훑으면 된다.

타일(아이콘·갤러리) 보기는 제목 옆이 아니라 그림 위 오른쪽 모서리이므로 기존
캡슐을 그대로 쓴다. 자리가 흔들리지 않는다.

보이스오버는 바뀌지 않았다. 줄 전체를 읽을 때 `ios.watch.new`를 그대로 덧붙인다.

## 3. 문구

| 키 | 한국어 |
|---|---|
| `ios.metadata.read_only` | 이 서버에는 파일을 쓸 수 없습니다. 검색 결과는 확인할 수 있지만 저장은 되지 않습니다. WebDAV로 연결하면 저장할 수 있습니다. |

## 남은 것

- 재생 화면에서 바로 영상 정보로 가는 길 (지금은 목록으로 나와야 한다)
- 시놀로지 FileStation 업로드
- 네트워크 목록은 서버의 `.nfo`를 읽지 않는다. 그래서 정보 화면이 "파일 이름에서
  짐작한 것"이라고 말한다. 서버에 `.nfo`가 이미 있으면 사실과 다르다

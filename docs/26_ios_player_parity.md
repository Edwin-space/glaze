# iPhone·iPad 플레이어 — 기본기 갖추기

작성일: 2026-09-06

`docs/25`가 남긴 두 가지(재생 미검증, 자막 미연결)를 닫고, 경쟁 플레이어들이
당연하게 갖춘 기능 중 빠져 있던 것들을 채웠다.

## 1. 고쳐진 결함

세 가지 모두 코드를 읽어서가 아니라 **시뮬레이터에서 실제로 영상을 틀어서** 드러났다.

### 자막이 재생기에 전달되지 않았다

`IOSLibraryModel`이 영상 옆의 자막을 찾아 `subtitleResources`에 담아두고 있었는데,
`IOSPlayerView`를 부르는 곳 어디에서도 그것을 넘기지 않아 기본값 `nil`이 들어갔다.
맥에서 만든 자막이 아이폰에서 안 보이는 상태였다 — 이 앱이 존재하는 이유와 정면으로
부딪히는 결함.

### 자막 크기 단위가 100배 틀려서 앱이 죽었다

```
Assertion failed: (scale >= 10 && scale <= 500), function vlc_player_SetSubtitleTextScale
```

VLC의 `currentSubTitleFontScale`은 **비율**(1.0 = 보통 크기)을 받는데 사람이 고르는
단위인 **퍼센트**(100)를 그대로 넘기고 있었다. 10000%를 요구한 셈이고, libVLC가
단언문에서 프로세스를 끝냈다. 재생을 누르면 앱이 사라졌다.

**tvOS에도 같은 코드가 있었다.** 애플TV의 libVLC 빌드는 단언문이 꺼져 있어 죽지는
않지만, 자막 크기 설정(85/100/125/150)이 전부 무의미했다는 뜻이다. 같이 고쳤다.

경계에서의 단위 변환을 `GlazeCore`의 `SubtitleScale`로 옮기고 테스트를 붙였다.
두 플레이어가 같은 곳을 쓴다.

### 버퍼링 표시가 영상 위에 영원히 남았다

`mediaPlayerBufferingChanged`가 주는 값은 퍼센트가 아니라 **0…1 비율**이다.
`progress < 100`은 언제나 참이라 회전자가 사라지지 않았다. 로그로 확인한 값:

```
buffering=0.139 → 0.417 → 0.555 → 0.973 → 1.0
```

### 검은 화면에 갇히는 길

재생 주소가 없는 항목을 누르면 `fullScreenCover`가 빈 화면을 띄우고 닫을 방법이
없었다. 이제 무엇을 열지 못했는지 말하고 닫기 단추를 준다.

### 상태 콜백이 한 번도 불리지 않았다

`mediaPlayerStateChanged`를 `Notification`을 받는 형태로 선언해 두었는데, VLCKit 4의
실제 선택자는 `VLCMediaPlayerState`를 받는다. 다른 선택자라 호출되지 않았고, 그래서
오류와 일시정지가 화면에 반영되지 않았다.

### 이름이 다른 자막

영상이 `Parasite.2019.1080p.mkv`이고 받아둔 자막이 `기생충.srt`이면 이름으로는
절대 이어지지 않는다. 라이브러리를 만들 때의 규칙(영상 이름으로 시작하는 자막만
붙인다)은 그대로 두고 — 그게 맞는 규칙이다 — 재생 중에는 **폴더를 다시 읽어 자막
파일을 전부 보여준다.** 이미 인식된 것에는 표시를 달아 구분한다.

## 4. 확인된 것 / 확인되지 않은 것

**시뮬레이터(iPhone 17 Pro, iOS 26.4)에서 실제로 확인:**
`test file/testmedia.mkv`(1.7GB MKV)를 파일 앱에서 열어 재생 — 영상이 그려지고,
시간이 흐르고, **프랑스어 자막이 알맞은 크기로 표시되고**, 음성 트랙(일본어)이 잡히고,
컨트롤바·트랙 시트가 모두 동작한다. 버퍼링 표시는 재생이 시작되면 사라진다.

**확인되지 않음:**

- **실기기 DLNA.** 시뮬레이터는 맥의 네트워크를 그대로 쓰고 로컬 네트워크 권한을
  강제하지 않는다. 시뮬레이터에서 NAS가 보인 것은 실기기의 증거가 되지 않는다.
  실제 아이폰에서는 권한 알림이 뜨고, 거부하면 조용히 실패한다 — 그 경우를 알려주는
  UI가 아직 없다. 멀티캐스트 권한이 필요한지도 확인해야 한다
- **NAS에서 스트리밍 재생.** 위와 같은 이유로 아직
- 4K·HDR·5.1을 실기기에서 재생했을 때의 발열과 배터리
- 아이패드 하단 탭 항목 중복 (`docs/25`)
- 이어보기는 기기마다 따로다. `PlaybackPositionStore`가 `UserDefaults`를 쓰므로
  맥에서 보다 만 영화를 아이폰이 알지 못한다. iCloud로 옮기는 것은 별도의 일

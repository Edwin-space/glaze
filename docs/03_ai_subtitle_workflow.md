# AI 자막 생성 워크플로우

작성일: 2026-06-18  
프로젝트명: 글레이즈

## 핵심 방향

글레이즈의 AI 자막 기능은 재생 중 실시간 생성보다 "재생 전 사전 생성"을 중심으로 설계한다.

실시간 생성은 기술적으로 매력적이지만, 실제 감상 경험에서는 지연, 발열, 배터리 소모, 탐색 시 누락 문제가 생길 수 있다. 따라서 초기 핵심 경험은 백그라운드 사전 생성으로 잡는다.

## 기본 흐름

1. 사용자가 영상을 추가한다.
2. 앱이 기존 자막 존재 여부를 확인한다.
3. 자막이 없으면 자막 생성 대기열에 추가한다.
4. 영상에서 오디오 트랙을 추출한다.
5. 오디오를 짧은 구간으로 나눈다.
6. 온디바이스 음성 인식 모델로 텍스트를 생성한다.
7. 문장 단위 타임스탬프를 정리한다.
8. 원어 자막 파일을 저장한다.
9. 필요하면 한국어 번역 자막을 생성한다.
10. 생성된 자막을 영상과 자동 연결한다.
11. 재생 시 즉시 자막을 표시한다.

## 자막 상태

영상별 자막 상태는 명확하게 표시한다.

- 자막 없음
- 생성 대기 중
- 오디오 추출 중
- 음성 인식 중
- 자막 정리 중
- 번역 중
- 완료
- 실패
- 일시정지됨

## 백그라운드 처리 정책

기본 정책은 사용자의 Mac을 방해하지 않는 방향으로 둔다.

- 전원 연결 시 자동 생성
- 배터리 사용 중에는 기본적으로 일시정지
- 사용자가 재생하려는 영상은 우선순위 상승
- 긴 영상은 낮은 우선순위로 천천히 처리
- 사용자가 직접 "지금 생성"을 누르면 즉시 처리
- 발열이나 시스템 부하가 높으면 자동 속도 조절

## 자막 저장 정책

두 가지 저장 방식을 지원한다.

### 앱 내부 저장

기본값으로 사용한다. 원본 영상 폴더를 건드리지 않고 앱이 관리한다.

장점:

- 사용자가 파일 구조를 몰라도 됨
- 권한 문제 감소
- 캐시 관리가 쉬움

### 영상 옆 파일 저장

사용자가 선택하면 영상 파일 옆에 자막을 저장한다.

예:

- `movie.mkv`
- `movie.original.srt`
- `movie.ko.srt`

장점:

- 다른 플레이어에서도 사용 가능
- 사용자가 자막 파일을 직접 보관 가능

## 모델 모드

사용자는 성능과 정확도 사이에서 선택할 수 있어야 한다.

- 빠른 모드: 작은 모델, 빠른 처리, 정확도 보통
- 표준 모드: 중간 모델, 균형형
- 고정확도 모드: 큰 모델, 느리지만 더 정확함

기본값은 표준 모드로 둔다.

## 번역 자막

한국 사용자를 기준으로 한국어 번역은 핵심 기능이다.

지원 표시 방식:

- 원문 자막
- 한국어 자막
- 원문 + 한국어 이중 자막

초기에는 원어 자막 생성 후 번역하는 후처리 방식을 사용한다. 이후 필요하면 문장별 스트리밍 번역이나 요약 번역을 검토한다.

## 실패 처리

실패는 조용히 숨기지 않고, 사용자가 이해할 수 있게 표시한다.

- 오디오 트랙 없음
- 지원하지 않는 코덱
- 모델 파일 없음
- 저장 권한 없음
- 처리 중 앱 종료
- 메모리 부족

실패한 작업은 재시도할 수 있어야 하며, 앱 재실행 후에도 대기열 상태가 유지되어야 한다.

## 개발 우선순위

1. 단일 영상 수동 자막 생성
2. 생성 자막 저장 및 자동 연결
3. 한국어 번역 자막 생성
4. 재생목록 내 자막 없는 영상 감지
5. 백그라운드 작업 큐
6. 전원/배터리 상태 기반 자동 처리
7. 작업 일시정지, 재개, 재시도
8. 영상 폴더 감시와 라이브러리 자동 준비

# 글레이즈 제품 방향

작성일: 2026-06-18  
최종 수정: 2026-08-10 (기초 재설계 결정 반영, 근거: `16_foundation_redesign_audit.md`)  
프로젝트명: 글레이즈

## 제품 정의

글레이즈는 macOS Apple Silicon 환경에서 시작하는 AI 미디어 라이브러리 플레이어다. 기본 사용자는 한국인이지만, 사용자가 시청하는 영상은 영어, 일본어, 중국어, 스페인어 등 다양한 언어일 수 있다.

글레이즈의 핵심은 단순 재생이 아니라, 개인 영상 파일을 이해하고, 영상의 음성을 온디바이스 AI로 분석해 자막을 만들고, 필요하면 한국어 번역 자막과 작품 메타데이터까지 준비하는 것이다.

## 핵심 가치

> 개인 영상 라이브러리를 AI가 감상 가능한 상태로 준비해주는 Apple Silicon 전용 미디어 플레이어

사용자는 자막 없는 영상이나 NAS/로컬 폴더의 영상을 추가하기만 하면 된다. 글레이즈는 작품 정보를 추정하고, 자막과 한국어 번역을 준비하며, 나중에 어떤 기기에서 보더라도 이어볼 수 있는 미디어 자산으로 정리한다.

## 목표 사용자

- 외국어 영상을 자주 보는 한국 사용자
- 자막이 없는 강의, 인터뷰, 세미나, 영화, 드라마, 유튜브 다운로드 영상을 보는 사용자
- NAS나 외장 디스크에 개인 영상 라이브러리를 보관하는 사용자
- Plex, Infuse, Apple TV처럼 여러 기기에서 이어보는 미디어 경험을 원하는 사용자
- 영어/일본어/중국어 등 외국어 학습 목적으로 영상을 보는 사용자
- 개인정보 보호를 위해 로컬 AI 처리를 선호하는 사용자

## 핵심 기능

### 1. 기본 영상 플레이어

- 로컬 영상 파일 재생
- 주요 포맷 지원: mp4, mov, mkv, avi, webm 등
- 재생 엔진 이원화: MP4/MOV는 AVKit, MKV/WebM/AVI는 네이티브 MKV 엔진
- 재생, 일시정지, 탐색, 배속 조절
- 전체화면, PIP
- 오디오 트랙 선택
- 자막 파일 로딩: srt, vtt, ass, ssa
- 최근 재생 목록
- 한국어 중심 UI

### 2. AI 자막 생성

- 영상에서 오디오 추출
- 언어 자동 감지
- 온디바이스 음성 인식
- 문장 단위 타임스탬프 생성
- 원어 자막 생성
- srt/vtt 파일 저장
- 기존 자막과 자동 연결

### 3. 한국어 번역 자막

- 원어 자막을 한국어로 번역
- 원문만 보기
- 한국어만 보기
- 원문 + 한국어 이중 자막 보기
- 자막 스타일, 위치, 크기, 배경 조절

### 4. 백그라운드 자막 준비

- 재생목록에 추가된 영상의 자막 존재 여부 확인
- 자막이 없으면 자동으로 생성 대기열에 추가
- Mac이 여유 있을 때 백그라운드 처리
- 전원 연결 시 자동 처리
- 배터리 사용 중 자동 중지 옵션
- 진행률, 실패, 재시도 상태 표시

### 5. 라이브러리 관리

- 영상 폴더 등록
- 재생목록 생성
- 자막 생성 상태 표시
- 작품 메타데이터 매칭 후보 표시
- 포스터, 줄거리, 장르, 출연진, 시즌/에피소드 정보 관리
- IMDb/TMDB/TVDB 같은 외부 ID 저장
- 생성된 자막 검색
- 영상별 자막/번역/요약 관리
- 추후 NAS, SMB, WebDAV 연동 검토

### 6. AI 확장 기능

- 파일명 기반 작품 정보 추정
- AI 미디어 어시스턴트: 자막, 번역, 메타데이터, 파일 정리 제안
- 영상 내용 요약
- 챕터 자동 생성
- 대사 검색
- 특정 문장 반복 재생
- 단어장 생성
- 어려운 표현 설명
- 자막 싱크 자동 보정

## 차별화 전략

기존 경쟁 제품은 대부분 다음에 강하다.

- 다양한 포맷 재생
- NAS/클라우드/미디어 서버 연동
- 메타데이터 관리
- 외부 자막 로딩
- 온라인 자막 다운로드

글레이즈는 다음에 집중한다.

- 자막이 없는 영상을 자동으로 자막화
- 재생 전에 자막을 미리 준비
- 한국어 번역 자막을 기본 경험으로 제공
- Apple Silicon의 Neural Engine, Metal, Core ML 활용
- 개인정보 보호를 고려한 로컬 AI 처리

Submarine Player처럼 AI 자막 생성과 번역을 이미 전면에 내세우는 제품도 있으므로, 글레이즈의 메시지는 더 선명해야 한다. 단순히 "AI 자막을 만든다"가 아니라, "한국어 사용자를 위해 영상 라이브러리를 미리 자막화하고 감상 가능한 상태로 준비한다"가 되어야 한다.

Submarine Player 대비 차별화 축:

- 실시간 생성 중심이 아니라 사전 생성과 백그라운드 준비 중심
- 글로벌 일반 사용자보다 한국어 감상 경험 중심
- 단일 파일 시청보다 라이브러리 전체의 자막 준비 상태 관리
- 생성 후 자막 수정, 검수, 저장, 재사용 흐름 강화
- 한국어 번역 품질과 이중 자막 UX를 핵심 품질로 관리
- 선택적 확장 방향으로 Chrome/Safari 브라우저 확장을 제공해, 사용자가 웹에서 보던 DRM 없는 영상을 글레이즈에서 열고 자막화할 수 있게 한다.

브라우저 확장 연동은 MVP 필수 기능이 아니라 2차 차별화 후보로 둔다. 사용자가 웹페이지에서 동영상을 발견했을 때 "글레이즈에서 열기"를 선택하면, HLS나 직접 미디어 URL을 감지해 앱으로 넘기고 글레이즈에서 재생/자막 생성/번역을 제공하는 방식이다. 단, DRM, 유료 접근 제어, 사이트 약관을 우회하는 기능은 제공하지 않는다.

## 제품 원칙

- AI는 앞에 나서지 않고 영상 감상을 돕는다.
- 기본 재생 경험은 가볍고 빠르게 유지한다.
- 자막 생성은 자동이지만 사용자가 언제든 제어할 수 있어야 한다.
- 배터리, 발열, 성능을 존중한다.
- 한국 사용자가 별도 설정 없이 바로 쓸 수 있어야 한다.
- 생성된 자막은 재사용 가능해야 한다.

## MVP 범위

첫 번째 MVP는 아래 범위를 목표로 한다.

- macOS 네이티브 앱
- Apple Silicon 전용
- 최소 macOS 15
- 시스템 언어 자동 감지 기반 한국어/영어 UI, 미지원 언어는 영어 fallback
- 로컬 영상 파일 재생
- 외부 자막 파일 로딩
- 단일 영상 수동 AI 자막 생성
- 생성 자막 저장
- 재생 시 생성 자막 자동 연결
- 한국어 번역 자막 생성
- 기본 자막 스타일 설정

## MVP 이후 우선순위

1. 재생목록 기반 자막 없는 영상 감지
2. 백그라운드 자막 생성 큐
3. 전원/배터리 상태 기반 처리 정책
4. 자막 생성 진행률과 실패 재시도
5. 라이브러리 폴더 감시
6. NAS/SMB/WebDAV 연동
7. 영상 요약과 챕터 자동 생성
8. 외국어 학습 모드
9. 생성 자막 편집과 검수
10. SRT/VTT/CSV 내보내기 및 이중 자막 파일 생성
11. Chrome/Safari 브라우저 확장 연동
12. DRM 없는 HLS/웹 영상의 글레이즈 열기
13. 작품 메타데이터 자동 매칭
14. 포스터/시즌/에피소드 기반 라이브러리 정리
15. iCloud 기반 시청 위치/자막 상태 동기화
16. Apple TV 보조 감상 앱
17. NAS/자체 미디어 서버 기반 거실 감상 경험

## 기술 방향

- 앱: SwiftUI
- 모듈 구조: 플랫폼 독립 `GlazeCore`(미디어 자산 모델, 자막 파싱, AI 자막/번역 엔진 인터페이스, Job Queue)와 macOS 전용 `GlazeMac`(AppKit/AVKit/VLC 재생 표면)으로 분리해, iOS 확장이 아키텍처를 막지 않도록 지금부터 반영한다
- 영상 재생: MP4/MOV는 AVKit, MKV/WebM/AVI 등은 네이티브 VLC 엔진. 텍스트 기반 내장 자막은 감지·추출·표시하며, 사용자 언어 트랙이 없으면 내장 cue를 번역 입력으로 우선 재사용한다
- 네트워크 미디어: 로컬 파일과 DLNA/UPnP 리소스를 동일한 `MediaResource` 경계로 다루고, macOS가 NAS 탐색·자막 준비의 중심, iOS/iPadOS/tvOS가 감상의 중심이 되는 구조를 유지한다
- 재생 엔진 배포 리스크: VLC/libVLC dlopen 동적 로딩 방식의 App Store 심사 통과 여부와 GPL 라이선스 정책을 다른 작업보다 먼저 조기 검증한다. 검증 결과에 따라 재생 엔진 선택이 바뀔 수 있다
- 음성 인식: Whisper 계열 온디바이스 모델 검토
- 모델 실행: Core ML, Metal, Neural Engine 활용
- 데이터 저장: SQLite 또는 Core Data
- 미디어 자산 모델: `MediaAsset` 중심으로 파일, 메타데이터, 자막 준비 상태, 시청 위치를 분리 관리
- 외부 메타데이터: IMDb/TMDB/TVDB 등 공급자를 추상화하고 라이선스/attribution/상업 사용 조건을 기능별로 검토
- 원본 파일 쓰기: 기본값은 앱 DB 또는 sidecar metadata 저장, 사용자가 명시적으로 선택할 때만 원본 컨테이너 태그에 반영
- 자막 포맷: srt, vtt 우선 지원
- 작업 큐: 앱 내부 persistent job queue
- UI: 커스텀 디자인 토큰을 최소화하고 Apple 표준 디자인 시스템(system tint, Material, SF Symbols, 시스템 텍스트 스타일)을 그대로 따른다. 상세 방향은 `11_ui_reference_design_direction.md` 참고

배포는 App Store를 목표로 하되, App Store 정책상 제공하기 어려운 고급 기능은 웹 배포 또는 별도 프리미엄 제품군으로 분리하는 방식을 검토한다.

글레이즈의 차별점은 AI 자막 준비 경험이다. MKV, 고해상도 등 기본 포맷 경쟁력은 네이티브 VLC 엔진으로 이미 핵심 가치를 검증하기에 충분한 수준을 확보했으므로, 이후 개발 리소스는 아직 코드가 전혀 없는 AI 자막 생성/번역 파이프라인에 우선 배분한다.

## 장기 포지션

글레이즈는 단순 영상 플레이어가 아니라, 개인 영상 라이브러리를 자동으로 이해하고 한국어 감상 환경을 만들어주는 AI 미디어 라이브러리 플랫폼으로 발전한다.

장기적으로는 macOS Apple Silicon에서 생성/정리 경험을 완성하고, iCloud 기반 시청 위치와 자막 상태 동기화, iPhone/iPad 보조 감상, Apple TV 거실 감상 앱, NAS/자체 미디어 서버 연동, Windows 데스크톱 제품군으로 순차 확장한다. 초기 UI 기본 언어는 한국어와 영어로 두고, 이후 일본어, 중국어, 스페인어 등 주요 국가 언어는 실제 유입과 결제 전환을 보며 확장한다.

# 애플TV — DLNA만으로는 비어 있던 이유, 그리고 폰과 같은 재생 경험 (2026-09-15)

## 1. DLNA만 연결하면 데이터가 안 들어왔다

"UPnP/DLNA로만 연결하면 불러오지 않고, WebDAV를 같이 넣어야만 된다"는 보고.

### 원인 — 재현으로 확정

애플TV의 선반은 DLNA 서버를 **깊이 4단계, 컨테이너 64개**까지만 훑어 만든 카탈로그로
채운다. 시놀로지 미디어 서버의 "폴더별" 트리는 이렇다:

```
0 → 비디오 → 폴더별 → video(공유) → 영화 → Dune (2021) → Dune.mkv
```

파일이 5~6단계 아래에 있다. 같은 모양의 가짜 서버로 재현했다:

| 파일 깊이 | 카탈로그가 찾은 영상 |
|---|---|
| 2 | 27 |
| 4 | 75 |
| **5** | **0** |
| **6** | **0** |

**그리고 더 나빴던 것:** TV는 이 카탈로그가 **비어 있지 않을 때만** 폴더 탭을 DLNA 서버에
연결했다. 그래서 선반도 비고, 새로 만든 폴더 탭까지 비었다. WebDAV를 함께 넣으면 WebDAV가
선반을 채워 "되는 것처럼" 보였던 것이다.

### 고친 것

- **서버를 고르는 즉시 폴더 탭에 연결하고 그 탭으로 옮긴다.** 카탈로그를 기다리지 않는다
- 시작할 때 복원된 서버도 `selectedServer`가 정해지는 순간 연결한다
- 홈 화면이 연결된 서버를 두고 **"연결하세요"라고 하지 않는다.** 선반이 비었으면 *"서버에
  연결됐습니다. 선반에 올릴 영상을 찾지 못했으니 폴더 탭에서 직접 열어보세요"* 와
  **폴더에서 열기** 버튼

카탈로그 한도를 **올리지 않았다.** 올리면 절벽이 한 칸 밀릴 뿐이고, 접속할 때마다 NAS 전체를
읽는 구조로 돌아간다 — 다른 곳에서 모두 걷어낸 그것이다. 깊은 서버의 길은 폴더 탐색이다.

회귀 테스트(`DLNADeepTreeTests`)는 카탈로그의 한도를 **고정해 둔다.** 누구도 깊은 서버에서
카탈로그가 영상을 찾으리라 가정하고 기능을 쌓지 않도록.

## 2. 폰과 같은 재생 경험

`docs/41`에서 아이폰에 넣은 것을 애플TV에 같은 규칙으로 넣었다. 대기열(`PlaybackQueue`)과
본 것 기록(`WatchState`)은 이미 공용 코드에 있었고, 화면만 붙였다.

| | 아이폰·아이패드 | 애플TV |
|---|---|---|
| ⏮ · ⟲10 · ⏯ · ⟳10 · ⏭ | ✓ | ✓ |
| 재생 목록 | 시트 | 오른쪽 패널, 지금 편에 포커스 |
| 끝나면 자동 다음, 폴더 끝에서 멈춤 | ✓ | ✓ |
| 5초 뒤엔 처음으로, 처음 몇 초에만 앞 편 | ✓ | ✓ |
| NEW / 보는 중 / 다 봄 | ✓ | ✓ |
| 목록에 화수 먼저 (`E01 · …`) | ✓ | ✓ |

- 편을 바꿀 때 **떠나는 편의 위치를 먼저 기록한다.** 끝까지 보고 저절로 넘어간 편이 NEW로
  남으면 안 된다 — TV는 플레이어가 닫힐 때만 기록하고 있었다
- 리모컨 **메뉴** 버튼은 재생 목록 → 자막 설정 → 플레이어 순으로 한 겹씩 닫는다
- 자막 선택 규칙을 폰 코드에서 공용 `SubtitleChoice`로 옮겼다. 같은 폴더를 두 기기가 다르게
  고르면 안 되므로

## 3. 덤 — 재생 버튼이 빈 주황 원이었다

확인 중에 발견했다. TV 전송부의 재생 버튼과, 자막이 켜진 자막 버튼이 **아이콘 없는 주황
원**으로 그려지고 있었다. 테두리 버튼은 아이콘을 틴트 색으로 칠하는데, 틴트가 주황이니
주황 위에 주황이었다. 나머지 버튼도 회색 위 회색이라 소파 거리에서는 거의 안 보였다.

아이콘 색을 직접 지정했다 — 주황 위엔 검정, 어두운 원 위엔 흰색. 이번 변경 전부터 있던
결함이다.

## 확인한 것 — 실제 WebDAV 서버로 끝에서 끝까지

맥에 PROPFIND와 범위 요청을 지원하는 작은 WebDAV 서버를 띄우고, `건담 0083` 폴더에 네 편을
넣어 애플TV 시뮬레이터에서:

- 폴더 탭: `E01~E04 · Gundam 0083`, 전부 **NEW**
- E02 재생: 실제 스트리밍, 프랑스어 자막 자동 선택, 전송부 다섯 버튼과 재생 목록 버튼
- 재생 목록 패널: `E01 NEW / ▶ E02 현재 / E03 NEW / E04 NEW`, 영상은 뒤에서 계속
- 아이콘 수정 전후 비교

TV 시뮬레이터는 창이 앞으로 오지 않아 리모컨 입력을 보낼 수 없었다. 폴더 탭으로 시작 /
두 번째 편 자동 재생 / 재생 목록 자동 열기를 하는 **임시 스위치**로 화면을 띄워 찍었고,
확인 뒤 **모두 제거했다**(`grep` 결과 0).

테스트 **334개** 통과. 세 앱 빌드, 우리 코드 경고 0.

## 확인하지 않은 것

- **실제 시놀로지의 DLNA.** 원인은 같은 모양의 가짜 서버로 재현했고 고친 경로도 코드로
  확인했지만, 진짜 NAS의 DLNA 트리에 붙여보지는 않았다
- **리모컨으로 직접 누르는 이전/다음과 목록 선택** — 화면과 상태는 봤지만 포커스 이동은
  손으로 해보지 못했다
- **자동 다음** — 51분짜리 영상을 끝까지 틀어보지 않았다
- **맥** — 재생 목록이 여전히 파일 이름이고 NEW 표시와 매체 키가 없다(`docs/41`)

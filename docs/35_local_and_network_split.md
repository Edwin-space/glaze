# 로컬과 네트워크를 가른다 (2026-09-08)

## 무엇이 문제였나

탭이 **보관함 / 서재 / 미디어 소스 / 설정**이었고, "보관함"은 **숨은 상태에 따라 정체가
바뀌는 화면**이었다. 다른 탭에서 무엇을 골랐느냐에 따라 전화기 안의 파일이기도 했고
NAS이기도 했으며, 제목까지 그 소스의 이름으로 갈아끼웠다.

화면이 자기가 무엇인지 말하지 않는다. 사용자는 **어느 소스를 골랐는지 기억하고 있어야**
지금 보는 것이 무엇인지 알 수 있었다. 그리고 전화기의 로컬 파일에는 포스터가 없으니,
포스터 격자는 대부분 빈 칸이었다.

전화기에서 로컬 파일과 NAS는 **다른 때에 다른 이유로** 쓴다 — 하나는 비행기에서,
하나는 집에서. 같은 화면일 이유가 없었다.

## 정한 것

| 탭 | 하나의 일 |
|---|---|
| **로컬** | Glaze 폴더를, 폴더 그대로 |
| **서재** | 책과 만화 |
| **네트워크** | 접속한 서버 목록 → 골라서 들어감 |
| **설정** | |

### 로컬 — 폴더를 그대로 보여준다

전화기의 영화는 사람이 만든 폴더로 온다. 영상과 자막과 `.nfo`가 한 폴더에.
**넣은 대로 보이는 것**이 가장 예측 가능하고, 기억할 숨은 상태가 없다.

- 폴더는 안에 영상이 몇 개인지 말한다
- 영상 줄은 `.nfo`가 있으면 **그 제목**을 쓴다 — 파일 이름이 아니라
- 크기와 옆에 있는 자막 수를 함께 보여준다
- 눌러서 바로 재생. 자막은 설정의 기본 언어에 맞는 것이 자동으로 붙는다

라이브러리 로더는 서재와 애플TV를 위해 트리 전체를 훑지만, 브라우저는 반대다 —
**지금 이 폴더만** 읽는다. 그래서 아래에 무엇이 얼마나 있든 폴더가 즉시 열린다.

### 네트워크 — 서버 목록이 뿌리다

주소가 여럿 연결될 수 있으므로, 탭의 뿌리는 **접속한 서버들의 목록**이다. 하나를
고르면 그 서버의 라이브러리가 그 위에 얹힌다 — 목록을 대체하지 않는다. 돌아오면
서버 목록이고, 다른 서버로 갈아탈 수 있다.

NAS에는 `.nfo`와 포스터가 갖춰져 있으므로 **서버 안에서는 포스터 격자를 그대로 쓴다.**
로컬과 모양이 다르지만, 각자 가진 데이터에 맞는 모양이다.

## 같이 없어진 것

- `IOSLibraryModel`의 device 소스 — 로컬은 이제 자기 폴더를 자기가 읽는다
- "미디어 소스"의 *이 기기의 영상* 줄 — 그게 로컬 탭이 되었다
- 실행할 때 기기에 영상이 있는지 뒤져 소스를 정하던 로직

## 확인한 것

시뮬레이터에서, 실기기와 같은 모양으로 두고:

```
Glaze/
  만화/            → 폴더
  풀린만화/         → 폴더
  Dune (2021)/     → 영상 1개
    Dune.2021.1080p.mkv
    Dune.2021.1080p.ko.srt
    Dune.2021.1080p.nfo
```

- 로컬 탭이 이 셋을 그대로 보여준다
- `Dune (2021)`에 들어가면 줄이 **`듄` · 1.7GB · 자막 1** — 파일 이름이 아니라
  `.nfo`가 말하는 제목이다

테스트 305개 통과. 맥·애플티비·아이폰 세 앱 모두 빌드된다.

## 확인하지 않은 것

- **실기기에서의 재생.** 구조만 바꿨고 재생 경로는 그대로지만, 실기기 재생은 여전히
  한 번도 확인되지 않았다
- **네트워크 탭 안쪽.** 서버에 붙지 못하고 있어(`docs/34`) 라이브러리가 얹히는 화면을
  실제로 보지 못했다
- 이어보기 표시가 로컬 목록에는 아직 없다 — 위치는 기억하지만 줄에 나타나지 않는다

## 로컬 폴더의 구조 (2026-09-08, 이어서)

파일을 기기로 넘길 때 폴더를 미리 갈라두자는 제안. **폴더는 만들되, 분류는
폴더로 하지 않는다.**

### 왜 폴더로 분류하지 않는가

파일의 종류는 확장자가 이미 말한다. `.mkv`는 영상이고 `.epub`은 책이다. 폴더로
분류하면 같은 사실을 두 군데에 적는 것이고, **둘이 어긋나는 날 파일이 사라진다**
— 영상 폴더에 들어간 PDF, 만화 스캔 폴더에 섞인 예고편. 이미 기기에 있는
`Dune (2021)/`처럼 루트에 만들어둔 폴더도 규칙이 되는 순간 보이지 않게 된다.

폴더가 **권유**일 때는 잃을 것이 없다. 넣을 자리가 분명해지고, 잘못 넣어도
제자리에 나타난다.

### 정한 것

- 첫 실행 때 `영상/`과 `서재/`를 만든다. **한 번만** — 지우는 사람은 지운 채로 둔다
- 이미 파일이 있는 사람에게도 만든다. 있는 것은 건드리지 않고 빈 폴더 둘만 생긴다
- 안내 메모는 **폴더가 비어 있을 때만** 쓴다. 남의 파일 사이에 끼워넣지 않는다
- 폴더 이름은 탭 이름과 **따로** 정한다(`ios.device.folder.*`). 탭 이름을 바꿨다고
  누군가의 파일이 든 폴더가 미아가 되면 안 된다
- 언어를 바꿔도 폴더가 둘로 늘지 않도록, `영상`/`Video`를 같은 자리로 본다
- 공유 시트로 들어온 파일은 종류에 맞는 폴더로 **들어간다**. 폴더가 실제로 일하는
  곳은 여기다 — 예전에는 전부 루트에 쌓였다
- 로컬 목록의 폴더 줄은 **책도 센다**(`영상 2개 · 책 5권`). 서재 폴더가 "폴더"라고만
  적혀 빈 것처럼 보이면 안 되므로

### 확인한 것

일부러 어긋나게 넣고 확인했다:

```
Glaze/
  영상/  미스터리 1권.cbz      ← 영상 폴더에 든 만화
  서재/  엉뚱한 영화.mkv       ← 서재 폴더에 든 영화
  Dune (2021)/                ← 루트에 그대로 있는 폴더
```

- 로컬 탭: `서재 — 영상 1개`, `영상 — 책 1권`, `Dune (2021) — 영상 1개`
- 서재 탭: **`미스터리 1권`이 그대로 있다** — 영상 폴더에 있어도

테스트 305개 통과. 맥·애플티비·아이폰 모두 빌드된다.

### 이름은 아직 정하지 않았다

탭은 `로컬`로 두었다. `네트워크`와 짝이 되어 **"어디에 있는가"**를 묻기 때문이다 —
전화기 안이면 로컬, NAS면 네트워크. `미디어`는 책도 미디어라 서재와 겹치고,
`로컬 미디어`는 탭 라벨로 길다.

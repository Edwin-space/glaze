# Mac App Store 영상 플레이어 벤치마크

작성일: 2026-06-18  
프로젝트명: 글레이즈

## 목적

Mac App Store 기준으로 사용성과 이용자 평점, 리뷰 수, 기능 범위가 강한 영상 플레이어를 확인하고, 글레이즈가 진입할 차별화 지점을 정의한다.

## 선정 기준

- Mac 지원 여부
- App Store 평점과 리뷰 수
- 단순 영상 편집기, OTT 앱, 카메라 앱 제외
- 로컬 파일, NAS, 클라우드, 미디어 서버 재생 경험
- 자막 기능과 라이브러리 관리 기능
- 한국 사용자에게 적용 가능한 UX 여부

## 추가 관찰 대상

아래 제품들은 App Store 공개 데이터에서 국가별 평점/리뷰 수가 0으로 확인되어 인기 상위 3개에는 넣지 않았지만, 기능 벤치마크 대상으로는 중요하다.

- Elmedia Video Player
- MKPlayer
- OmniPlayer
- Movist

특히 Movist는 한국 개발 제품이며, 고품질 자막과 FFmpeg/QuickTime 디코더 선택, Apple Silicon 지원 측면에서 한국 사용자 UX를 참고할 가치가 있다.

## 핵심 영감/직접 레퍼런스: Submarine Player

Submarine Player는 글레이즈와 가장 가까운 문제를 이미 제품화한 직접 레퍼런스다. App Store와 공식 웹사이트 기준으로 Apple Silicon 및 macOS 15 이상을 요구하며, 영상 재생 중 AI로 자막을 실시간 생성하고 번역하는 것을 핵심 가치로 내세운다.

확인된 주요 특징:

- Apple Silicon 전용에 가까운 포지셔닝: M1 이상 Mac, macOS 15 이상 요구
- 모든 일반 영상 포맷 재생을 전면에 제시
- 영상 재생 중 실시간 자막 생성
- 온디바이스/오프라인 처리와 개인정보 보호 강조
- 19개 언어 전사 및 번역 지원
- 원문 자막만 표시하는 transcription-only 모드
- 성능/정확도에 따른 복수 전사 모델 선택
- 원문 + 번역 이중 자막
- SRT, VTT, CSV 자막 파일 내보내기
- 여러 영상을 한 번에 처리하는 배치 처리
- 구독형 Plus와 평생 구매 옵션 제공

Submarine Player에서 배울 점:

- 제품 메시지가 매우 선명하다. "자막을 찾기 어렵다"는 문제를 "보는 동안 바로 자막이 나타난다"는 결과로 연결한다.
- AI 기능을 복잡하게 설명하지 않고, 사용자가 얻는 결과인 자막 생성, 번역, 이중 자막, 내보내기 중심으로 표현한다.
- Apple Silicon과 오프라인 처리를 강하게 묶어 개인정보 보호와 성능 이미지를 만든다.
- 언어 학습 사용자를 위해 원문/번역 이중 자막을 핵심 기능으로 둔다.
- 배치 처리와 자막 내보내기를 통해 "플레이어"를 넘어 "자막 생성 도구"로 확장한다.

Submarine Player 대비 글레이즈의 차별화 방향:

- Submarine Player는 실시간 생성 경험을 강하게 내세운다. 글레이즈는 재생 전 사전 생성과 백그라운드 준비를 더 강한 중심 경험으로 삼는다.
- Submarine Player는 글로벌 언어 접근성을 전면에 둔다. 글레이즈는 한국 사용자의 기본값, 한국어 번역 품질, 한국어 UI, 한국식 자막 감상 경험을 더 깊게 설계한다.
- Submarine Player는 단일 파일 시청과 배치 처리 도구에 가깝다. 글레이즈는 개인 영상 라이브러리 전체의 자막 준비 상태를 관리하는 방향으로 확장한다.
- Submarine Player 리뷰에서는 문맥 기반 번역, 자막 편집, SRT/CC 수정, 영상에 자막 삽입 같은 요구가 드러난다. 글레이즈는 생성 후 검수/수정/재사용 흐름을 초기에 설계해 차이를 만들 수 있다.

제품 전략상 Submarine Player는 "영감을 준 앱"이자 가장 직접적인 검증 사례다. 따라서 글레이즈는 Submarine Player를 단순히 따라가는 것이 아니라, 아래 질문에 답해야 한다.

> 실시간 자막 생성 앱이 이미 있다면, 왜 사용자는 글레이즈를 선택해야 하는가?

현재 답은 다음과 같다.

> 글레이즈는 자막을 보는 순간 만드는 앱이 아니라, 내 영상 라이브러리를 미리 자막화해서 언제든 편하게 볼 수 있게 준비하는 한국어 중심 AI 플레이어다.

## 경쟁 제품 공통 패턴

인기 영상 플레이어들은 대체로 아래 기능을 중심으로 경쟁한다.

- 다양한 파일 포맷 재생
- 4K, HDR, Dolby Vision, Dolby/DTS 오디오 지원
- NAS, SMB, WebDAV, 클라우드, 미디어 서버 연동
- 메타데이터와 포스터 기반 라이브러리 관리
- 외부 자막 로딩 및 온라인 자막 다운로드
- Apple 생태계 연동: iPhone, iPad, Mac, Apple TV, Vision

## 비어 있는 기회

경쟁 제품들은 "있는 자막을 잘 붙이는" 방향이 강하다. 하지만 "자막이 없는 영상 자체를 자동으로 자막화하는" 기능은 아직 핵심 경험으로 자리 잡지 않았다.

다만 Submarine Player처럼 실시간 AI 자막 생성과 번역을 이미 핵심으로 내세우는 제품이 등장했기 때문에, 글레이즈의 차별화는 더 구체적이어야 한다. 단순히 "AI 자막 생성이 된다"는 메시지만으로는 부족하다.

글레이즈가 잡을 수 있는 기회는 다음과 같다.

- 자막 없는 영상의 자동 자막 생성
- 재생 전 자막 파일 사전 생성
- 재생목록에 추가된 영상의 백그라운드 자막 준비
- 원어 자막과 한국어 번역 자막의 자동 생성
- Apple Silicon 온디바이스 AI 처리
- 한국 사용자를 위한 기본값과 자막 UX
- 생성된 자막의 검수, 수정, 재사용, 내보내기 흐름
- 개인 영상 라이브러리 단위의 자막 준비 상태 관리

## 결론

글레이즈가 Infuse와 정면으로 "최고의 범용 플레이어" 경쟁을 하는 것은 초기 전략으로 적합하지 않다. 대신 Infuse/VidHub류의 라이브러리 플레이어 경험을 기본으로 참고하되, 제품의 중심 가치를 "AI 자막 준비"에 둬야 한다.

Submarine Player의 등장은 글레이즈의 방향이 시장적으로 유효하다는 근거이면서 동시에 경고다. 글레이즈는 실시간 자막 생성 기능 자체보다, 한국어 감상 경험과 사전 자막 준비, 라이브러리 자동화, 생성 후 수정/관리 경험을 더 깊게 설계해야 한다.

제품 포지션:

> 글레이즈는 자막이 없는 다국어 영상을 Apple Silicon 온디바이스 AI로 미리 자막화하고, 한국어 감상 경험까지 준비해주는 macOS 영상 플레이어다.

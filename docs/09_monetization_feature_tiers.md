# 수익화 필터링 및 기능 태그 전략

작성일: 2026-06-18  
최종 수정: 2026-11-09 (출시 수익모델 검토 추가, 상품·가격 미확정)
프로젝트명: 글레이즈 / Glaze

## 문서 목적

이 문서는 글레이즈의 기능 구현 이후 무료/유료/Pro/Premium 여부를 판단하기 위한 필터링 기준을 정리한다. 현재 시점에서 가격, 상품명, 무료/유료 경계, 구독/일회성 구매 여부를 확정하지 않는다.

우선순위는 제품 가치 구현이다. 기능을 먼저 만들고, 이후 App Store 정책, 사용자 반응, 유지 비용, 계산 비용, 법적/저작권 리스크, 경쟁 제품 포지션을 기준으로 무료/유료/Pro/Premium 여부를 필터링한다.

## 기본 방향

글레이즈는 기능을 구현할 때부터 나중에 티어를 나눌 수 있는 구조를 고려한다. 다만 개발 초기에는 특정 기능을 반드시 무료 또는 유료로 고정하지 않는다.

나중에 검토할 수익화 방식:

- 구독형
- 일회성 구매 풀버전
- App Store 인앱 구매
- 웹 배포판의 Glaze Pro/Premium

App Store 정책상 문제가 없는 기능은 App Store 내부에서 유료화할 수 있다. App Store 정책 또는 심사 리스크가 있는 기능은 웹 배포/프리미엄 제품군으로 분리할 수 있다. 이 판단은 기능이 구현되고 실제 심사 리스크가 더 명확해진 뒤 진행한다.

## 무료 후보 태그

아래 기능은 무료 후보 태그를 붙일 수 있다. 확정이 아니라 후속 필터링의 출발점이다.

후보:

- 로컬 영상 파일 재생
- 기본 재생 컨트롤
- 외부 SRT/VTT 자막 로딩
- 기본 자막 표시/숨김
- 기본 자막 스타일 설정
- 제한된 횟수 또는 제한된 길이의 AI 자막 생성 체험
- 제한된 횟수의 한국어 번역 자막 체험
- 앱 내부 저장
- 한국어/영어 UI

무료 후보의 목적은 "이 앱이 내 영상 문제를 해결한다"는 감각을 주는 것이다. 너무 많이 막으면 제품 가치를 체험하지 못하고, 너무 많이 열면 지속 가능한 수익화가 어렵다. 이 균형은 기능 구현 후 사용성 테스트를 통해 조정한다.

## 유료 후보 태그

아래 기능은 유료 후보 태그를 붙일 수 있다. 이 역시 확정이 아니라, 구현 후 사용량과 가치가 확인되면 유료화 여부를 판단한다.

후보:

- 긴 영상 AI 자막 생성
- 무제한 또는 높은 한도의 자막 생성
- 한국어 번역 자막 무제한 생성
- 원문 + 한국어 이중 자막
- 고정확도 모델
- 배치 자막 생성
- 재생목록 기반 자동 자막 준비
- 백그라운드 작업 큐
- 생성 자막 자동 재사용/관리
- SRT/VTT/CSV 내보내기
- 자막 편집/검수 도구
- 자막 싱크 보정
- 고급 자막 스타일
- 영상 요약과 챕터 자동 생성
- 외국어 학습 모드

## Pro/Premium 후보 태그

아래 기능은 App Store 정책, 라이선스, 배포 방식, 저작권/DRM 리스크를 검토한 뒤 App Store 유료 기능 또는 웹 배포판 Pro/Premium 기능으로 분리할 수 있다. 현재는 "주의해서 관리할 기능"이라는 태그로만 둔다.

후보:

- FFmpeg 기반 고급 코덱 지원
- MKV 고급 지원
- 특수 오디오 트랙 처리
- Chrome/Safari 브라우저 확장 연동
- DRM 없는 HLS/웹 영상 열기
- 허용된 미디어 저장 기능
- 고급 다운로드/저장 워크플로우
- 웹 배포판 전용 기능
- 대용량 배치 처리
- 고급 로컬 모델 다운로드/관리
- NAS/자체 미디어 서버 연동
- Apple TV 앱과 여러 기기 이어보기
- iCloud 또는 계정 기반 시청 위치/자막 상태 동기화
- 작품 메타데이터 자동 매칭과 라이브러리 정리
- 원본 파일 태그/메타데이터 쓰기 도구

이 목록은 정책 위반 기능을 만들겠다는 뜻이 아니다. App Store에서 제공하기 어렵거나 설명이 복잡한 기능을 별도 제품군으로 분리할 가능성을 관리하기 위한 목록이다.

특히 "MKV 고급 지원"은 현재 네이티브 VLC 엔진으로 구현되어 있다. 2026-08-10 1차 검증에서는 `Tools/vlc/plugins`에 GPL 전용 모듈(x264, dvdnav, dvdread, goom 등)이 섞여 있어 App Store 배포 "불가"로 평가했으나, 같은 날 플러그인 전수 검사 후 GPL/불필요 모듈 74개를 제거하고(265개 LGPL 확인 유지) 재생 회귀 테스트까지 완료했다. "MKV 고급 지원"의 App Store 가능성은 이제 "가능"으로 재평가한다(`16_foundation_redesign_audit.md` §2.3, `Tools/vlc/LICENSE-THIRD-PARTY.md` 참고). 단, 실제 제출 전 라이선스 전문가 검토는 별도로 권장한다.

## 구독형과 일회성 구매 검토 기준

### 구독형 후보 기준

구독은 지속적인 업데이트, 모델 개선, 번역 품질 개선, 여러 기기 동기화, 고급 AI 기능처럼 지속 비용이 있는 기능에 적합하다. 현재는 후보 기준으로만 관리한다.

후보:

- 고정확도 AI 자막 생성
- 지속 업데이트되는 모델
- 고급 번역 모델
- 여러 기기 동기화
- 클라우드/웹 연동 기능
- 대량 처리
- 브라우저 확장과 앱 연동

### 일회성 구매 후보 기준

일회성 구매는 로컬 기능 중심이고 지속 서버 비용이 낮은 기능에 적합하다. 현재는 후보 기준으로만 관리한다.

후보:

- 기본 풀버전 잠금 해제
- 로컬 자막 생성 한도 해제
- 고급 플레이어 기능
- 고급 자막 스타일
- 파일 내보내기
- 로컬 라이브러리 관리

## 후속 필터링 예시

아래는 현재 시점의 상품 구조 확정안이 아니다. 기능 구현 후 필터링할 때 사용할 수 있는 예시다.

### Free

- 기본 영상 재생
- 외부 자막 로딩
- 제한된 AI 자막 생성 체험
- 제한된 번역 체험

### Glaze Plus 또는 Glaze Pro

- 자막 생성 한도 확대 또는 무제한
- 한국어 번역 자막
- 이중 자막
- 자막 저장/내보내기
- 고정확도 모델
- 배치 처리

### Glaze Premium 또는 웹 배포판 Pro

- App Store 정책상 분리가 필요한 기능
- 고급 코덱/FFmpeg 기능
- 브라우저 확장 기반 웹 영상 열기
- 허용된 미디어 저장
- 고급 로컬 모델 관리

상품명은 아직 확정하지 않는다. `Glaze Pro`, `Glaze Premium`, `Glaze Plus`는 후속 후보명으로만 둔다.

## 기능 기획 시 필수 표기

앞으로 기능을 문서화할 때는 각 기능에 아래 필드를 함께 적는다. 이 필드는 가격을 확정하기 위한 것이 아니라, 나중에 필터링할 때 판단 근거를 잃지 않기 위한 기록이다.

- 기능명
- MVP 포함 여부
- 무료/유료 후보
- App Store 제공 가능성
- 웹/Pro 분리 가능성
- 정책 리스크
- 계산 비용
- 사용자 가치

예:

| 기능 | MVP | 무료/유료 후보 | App Store 가능성 | Pro 분리 가능성 |
|---|---|---|---|---|
| 로컬 영상 재생 | 포함 | 무료 | 높음 | 낮음 |
| 단일 영상 AI 자막 생성 | 포함 | 무료 체험 + 유료 확장 | 높음 | 낮음 |
| 배치 자막 생성 | 제외 | 유료 | 높음 | 중간 |
| 브라우저 HLS 열기 | 제외 | Pro 후보 | 검토 필요 | 높음 |
| 허용된 미디어 저장 | 제외 | Pro 후보 | 검토 필요 | 높음 |

## 개발 단계에서 지킬 점

- 무료/유료 경계를 지금 확정하지 않는다.
- 기능 구현은 제품 가치와 사용자 흐름을 우선한다.
- 나중에 티어를 나눌 수 있도록 기능 플래그와 사용량 측정 가능성을 고려한다.
- 무료 사용자가 제품 가치를 체험할 수 있어야 한다.
- 유료 전환은 기능 잠금보다 시간 절약, 품질, 자동화, 대량 처리에서 만들어야 한다.

## 2026-11-09 · 출시 수익모델 제안 (결정 전)

**권고: 무료 기본 플레이어 + 일회성 Pro 잠금 해제. 초기 출시에는 광고를 넣지 않는다.**
이것은 제품 방향 제안이며 실제 무료/유료 경계나 판매 가격을 확정하지 않는다.
이번 변경에 광고 SDK, 추적, 결제 코드, 유료 상품 등록은 포함하지 않았다.

| 모델 | 사용자 경험 / 개인정보 | 1인 개발 운영 부담 | 판단 |
|---|---|---|---|
| 무료 + 광고 + 일회성 광고 제거 | 무료 진입은 쉽지만 개인 NAS 플레이어에 광고가 끼어드는 비용이 큼. SDK 데이터 흐름이 추가됨 | 광고 SDK·동의·플랫폼 지원·구매 복원까지 관리 | 가능하지만 후순위 |
| 무료 기본 + 일회성 Pro | 영상 감상은 방해하지 않고 배치 처리·라이브러리 자동화의 시간 절약에 과금 | 공통 StoreKit 권한 계층과 복원 관리 | 우선 권고 |
| 구독 | 지속 제공되는 가치와 비용에 대한 설명 필요 | 지속적 서비스 운영·해지·갱신 상태 관리 | 실제 클라우드 비용/서비스가 생길 때 재검토 |

### 무료와 Pro 경계의 출발점

- 무료 유지 후보: 로컬/NAS 기본 재생, 내장·외부 자막 선택, 언어 기본값, 크기·위치·싱크,
  접근성, 네트워크 오류 복구, 진단 내보내기. 필수 기능이나 결함 수정을 유료화하지 않는다.
- Pro 후보: 여러 영상 일괄 자막 준비, 작업 큐/예약, 다중 언어 출력, 라이브러리 자동 정리,
  고급 모델 관리. 이미 제공한 기능을 갑자기 잠그지 않고 출시 전 경계를 별도로 승인받는다.
- 단순 로컬 연산을 서버 사용료처럼 설명하지 않는다. 무제한 번역 약속은 실제 계산량과
  플랫폼별 가능 기능을 검증한 뒤 결정한다.

### 광고 모델을 선택한다면

1. 광고 위치는 라이브러리의 명확한 광고 슬롯에 한정한다. 재생 전·중·후 강제 광고,
   일시정지 화면, 자막 위, 타임라인 위, 네트워크 연결/오류 복구 도중 광고는 제외한다.
2. 개인화 없는 문맥형 광고를 우선 검토한다. 영상명·자막·NAS 주소·계정·진단 로그를
   광고 타기팅이나 광고 분석에 보내지 않는다. 광고 실패 시 앱이 멈추거나 재생을 막지 않는다.
3. 광고 제거는 비소모성 일회성 인앱 구매로 구현하는 안을 검토한다. 구매 완료뿐 아니라
   검증된 entitlement, 환불/취소, 재설치, 다른 기기 복원, 오프라인 상태를 시험한다.
   로컬 Bool이나 iCloud 설정 파일만으로 유료 권한을 결정하지 않는다.
4. 같은 App Store Connect 앱의 여러 플랫폼에서 제공할 상품을 설계하고 각 타깃에서
   구현·검증한다. 다른 번들/스토어 간 구매 공유가 자동으로 된다고 약속하지 않는다.
5. SDK 선정 전 네이티브 macOS·iOS·tvOS 지원, 샌드박스, 개인정보 manifest/서명 요구,
   실제 수집 항목, SDK 라이선스, 연령 등급·광고 적합성을 확인한다.
6. **모든 광고가 ATT 대상인 것은 아니다.** iOS/iPadOS/tvOS에서 타사 앱/사이트 간 추적이나
   광고 식별자 접근이 있으면 ATT 등 해당 요구를 확인한다. 문맥형 광고여도 SDK 수집이
   0이라고 추정하지 않는다. 도입 전에 정책·App Privacy 응답·인앱 설명을 함께 갱신한다.

### 손익 검토 방식

광고 월 총매출 = 일 활성 사용자 × 1인 하루 노출 × 30일 × 충전율 × eCPM / 1,000.
예를 들어 DAU 1,000명, 하루 3회, 충전율 80%, eCPM 2달러를 **가정**하면 월 144달러다.
이 숫자는 시장 단가나 매출 예측이 아니라 민감도 계산 예시다. 광고 재생을 늘려 단가를
맞추는 방향으로 플레이어 경험을 훼손하지 않는다.

일회성 구매 총매출은 **신규 결제자 수 × 가격**이다. 같은 사용자가 매달 다시 결제하는
구독 매출로 계산하지 않는다. 두 모델 모두 수수료·세금·환불·지원·SDK 운영 비용을
뺀 순기여로 비교한다. 가격·전환율은 아직 제안/확정하지 않았다.

### 구현 단계 / 상대 공수

- 공통 StoreKit 2 entitlement·구매·복원·테스트 화면: 중간.
- 이미 있는 기능에 대한 권한 경계와 무료 사용자 오류/오프라인 처리: 중간.
- 광고 추가: 위 구매 기반에 더해 SDK·동의·플랫폼별 배치·개인정보 검토가 추가되므로 큼.
- 초기안은 광고 없이 무료 배포로 안정성을 확보하고, Pro 후보를 승인한 후 StoreKit 기반을
  별도 변경으로 넣는다. 판매 심사 신청에 새 수익모델을 묵시적으로 포함하지 않는다.

확인 근거 (2026-11-09, 정책은 실제 도입 시 재확인):

- [Apple Business Models](https://developer.apple.com/app-store/business-models/)
- [App Review Guidelines 3.1.1 / 2.5.18 / 5.1](https://developer.apple.com/app-store/review/guidelines/)
- [User Privacy and Data Use](https://developer.apple.com/app-store/user-privacy-and-data-use/)
- [StoreKit currentEntitlements](https://developer.apple.com/documentation/storekit/transaction/currententitlements)
- [Configure In-App Purchases](https://developer.apple.com/help/app-store-connect/configure-in-app-purchase-settings/overview-for-configuring-in-app-purchases/)
- App Store 버전에서 웹 결제 우회를 유도하면 안 된다.
- 구독형과 일회성 구매를 동시에 제공할 경우 상품 설명이 매우 명확해야 한다.
- 온디바이스 기능이라도 모델 다운로드, 업데이트, 고급 기능 유지에는 비용이 있을 수 있다.
- 다운로드/웹 영상 관련 기능은 저작권, DRM, 사이트 약관을 먼저 검토해야 한다.

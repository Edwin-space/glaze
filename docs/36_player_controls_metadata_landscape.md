# 재생 컨트롤, 정보 수정, 가로 보기 (2026-09-08)

## 1. 컨트롤이 사라지면 돌아오지 않았다

### 원인

`IOSVideoSurface`는 VLC가 그리는 UIKit 뷰다. **그 뷰가 터치를 전부 삼키고 있었다.**

컨트롤이 떠 있는 동안에는 컨트롤이 그 위를 덮고 있어서 아무 문제도 보이지 않는다.
5초 뒤 컨트롤이 숨으면 손가락 아래에 남는 것은 영상 뷰뿐이고, 화면을 아무리 눌러도
`.onTapGesture`에 도달하지 못한다. **영상을 닫는 것 말고는 컨트롤로 돌아갈 길이
없었다.**

### 고친 것

그림은 컨트롤이 아니다. 그래서 터치를 받지 않는다.

- `IOSVideoSurface`에 `.allowsHitTesting(false)`
- 그 위에 스위프트UI가 소유하는 투명한 제스처 층을 둔다. 노치와 홈 인디케이터
  아래까지 화면 전체를 덮는다(`ignoresSafeArea`)
- 탭과 드래그(밝기·음량·탐색)가 모두 이 층으로 옮겨졌다

### 확인한 것 — 대조 실험

같은 입력(터치 다운 → 90ms → 업)으로:

| 빌드 | 결과 |
|---|---|
| 고치기 전 | 컨트롤이 **돌아오지 않는다** |
| 고친 뒤 | 컨트롤이 **돌아온다** |

즉발 합성 탭은 스위프트UI 탭 제스처를 깨우지 못한다 — 처음 "재현"했을 때 이것을
버그로 오인할 뻔했다. 머무는 시간이 있는 진짜 손가락 형태로 다시 재현해서
원인을 확정했다.

### 겸사겸사 — 멈춰 있을 때는 숨지 않는다

컨트롤은 영상을 가리지 않으려고 비켜서는 것이다. **멈춰 있으면 가릴 영상이 없다.**
자막을 읽으려고, 설정을 찾으려고, 화면을 돌리려고 멈춘 사람이 버튼을 두 번 눌러
제자리로 돌려놓을 이유가 없다.

## 2. 잘못 들어간 영상 정보를 고칠 수 있다

남의 스크레이퍼가 쓴 `.nfo`는 자주 틀리고, 지금까지 전화기에는 **틀렸다고 말할
방법이 없었다.** 파일이 주장하는 것이 곧 제목이었다.

- **설정 › 메타데이터**에 TMDB API 키. 앱에 넣어 배포하지 않는다 — 유료 앱에서 키를
  재배포하는 문제가 정리되지 않았고(`docs/23`), 공용 키는 전 세계 사본이 하나의
  요청 한도를 나눠 쓰게 된다
- 목록에서 **영상을 길게 누르면 "영상 정보"**
- 지금 기록된 제목·연도·줄거리와, **그것이 어디서 왔는지**(.nfo인지 파일 이름인지).
  고칠 값어치가 있는지 판단하게 하는 것이 그 한 줄이다
- 제목을 고쳐 다시 검색할 수 있다. 파싱이 틀린 것이 문제의 원인일 수 있으므로
- 고른 뒤 **한 번 더 확인**하고 나서야 쓴다. 디스크의 파일을 덮어쓰는 일이므로
  목록의 탭 한 번으로 일어나면 안 된다
- 결과는 영상 옆의 `.nfo`와 `-poster.jpg`. **맥과 애플TV가 읽는 바로 그 파일이다.**
  여기서 고치면 그 폴더를 여는 모든 곳에서 고쳐진다

검색어를 손대지 않았을 때만 기존 연도로 범위를 좁힌다. 틀린 기록에서 온 연도로
좁히면 같은 틀린 답으로 되돌아간다.

## 3. 버튼 하나로 가로 보기

침대에서 보는 사람은 화면 회전 잠금을 켜 두었고, 영화 한 편 때문에 껐다 켜지
않는다. 버튼이 없으면 21:9 영화가 세로 화면 가운데 띠로 재생되고 할 수 있는 일이
없다.

- 상단 바에 `rectangle.landscape.rotate`. 누르면 가로로 돌아가 **거기 머문다**
- 아이콘은 화면이 아니라 **버튼이 할 일**을 보여준다. 손으로 돌렸을 때 아이콘이
  덩달아 바뀌면 안 되므로
- 영상을 닫으면 놓아준다. 플레이어의 `.onDisappear`와 **세 군데 발표자 모두의
  `onDismiss`** 양쪽에서. 한쪽이 건너뛰어져 앱 전체가 가로로 갇히면 안 되므로

### 왜 앱 델리게이트가 생겼나

iOS는 요청받은 방향을 **지금 지원한다고 말하는 경우에만** 허락한다. 그 답을 하는
곳이 앱 델리게이트이고 스위프트UI에는 대신할 방법이 없다. `IOSAppDelegate`는
그 메서드 하나 때문에 존재한다.

**그리고 iOS가 묻는 것은 루트가 아니라 가장 위에 발표된 컨트롤러다.** 플레이어는
전체 화면 커버 — 자기 컨트롤러 — 이므로 루트에게만 알리면 답이 낡은 채로 남고
요청은 그대로 거부된다. 처음 붙였을 때 아무 일도 일어나지 않은 이유가 이것이었다.
발표 사슬 전체에 알린 뒤에 통과한다.

## 4. 확장자가 제목에 남아 있었다

`엉뚱한 영화.mkv`가 목록에 **"엉뚱한 영화 mkv"**로 나왔다.

확장자를 떼는 일이 호출자에게 맡겨져 있었고 **여섯 중 맥 하나만** 하고 있었다.
그런데도 대부분 드러나지 않은 이유는, 이름에 연도가 있는 파일은 연도에서 잘라내는
처리가 확장자까지 부수적으로 버렸기 때문이다. 연도가 없는 이름만 남았다.

아는 자리인 파서에서 처리한다 — 이 앱이 재생하는 컨테이너의 확장자만. `Se7en`은
그대로 두고, `영화.avi.mkv`는 마지막 것만 뗀다.

## 확인한 것

- 컨트롤 복귀 — 대조 실험으로 원인 확정
- 길게 눌러 정보 화면, 키가 없을 때의 안내
- 가로 보기 — 버튼을 눌러 화면이 실제로 돌아감
- 제목에서 확장자가 사라짐

테스트 308개 통과. 맥·애플티비·아이폰 모두 빌드된다.

## 확인하지 않은 것

- **가로에서 세로로 되돌리는 버튼과, 닫을 때의 해제.** 시뮬레이터가 가로 인터페이스일
  때 합성 탭의 좌표계가 어긋나 버튼을 정확히 누르지 못했다. 코드로는 두 겹으로
  걸어두었지만 눈으로 보지는 못했다
- **TMDB 검색과 쓰기 자체.** API 키가 없어 실제 검색 결과와 `.nfo` 쓰기를 보지 못했다.
  키를 넣고 확인이 필요하다

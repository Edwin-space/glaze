# 디자인 규격 점검과 정보 패널 (2026-09-08)

## 1. 플레이어 컨트롤 — 규격을 지키지 않고 있었다

승인된 플레이어 계약(`docs/17`)의 해당 조항:

> 각 버튼은 clear Liquid Glass 또는 반투명 material을 사용하되 **하나의 캡슐로 합쳐
> 보이지 않게 한다.**
> 중앙에는 뒤로, 재생·일시정지, 앞으로를 **개별 원형 버튼**으로 둔다.
> **재생 버튼만 한 단계 크게** 표시한다.
> 밝은 영상에서도 **버튼과 timeline이 식별**되며 전체 화면을 덮는 dim layer를
> 사용하지 않는다.

맥은 `GlazeGlass.Depth.transport`(ultraThinMaterial + 0.08 검정 + 흰 0.16 테두리)로
이것을 지키고 있었다. **아이폰은 지키지 않고 있었다.**

| | 이전 | 지금 |
|---|---|---|
| 상단 버튼 | `.black.opacity(0.45)` 납작한 검정 원 | 반투명 material + 미세한 어둠 + 헤어라인 |
| 재생·앞뒤 | **배경 없는 글리프** — 밝은 프레임에서 묻힌다 | 개별 유리 디스크, 재생만 한 단계 크게(68 / 52) |
| 속도·잠금·제스처 표시 | 각자 다른 검정 불투명도(0.45 / 0.55 / 0.6) | 모두 같은 처리 |

납작한 검정 원은 **자기가 앉은 프레임을 지워버린다.** 계약이 material을 요구하는
이유가 그것이다. 숫자는 `IOSTheme.Transport` 한 곳에 있고 `glazeTransportDisc()`가
그것을 쓴다 — 화면마다 검정 불투명도를 고르던 상태로 되돌아가지 않도록.

### 제목이 한 글자로 잘려 있었다

버튼이 일곱 개가 되면서 제목이 닫기 버튼과 나머지 사이에서 **"엉"** 한 글자가 됐다
(엉뚱한 영화). 제목은 컨트롤이 아니고 컨트롤과 한 줄을 나눠 쓸 이유가 없다.
아래 줄로 내렸다.

### 지키지 않은 채 남겨둔 것

`docs/17`은 "15초 뒤로/앞으로"라고 적혀 있는데 **세 플랫폼 모두 10초**로 구현되어 있다
(`gobackward.10`). 코드가 아니라 문서가 낡았을 가능성이 높지만, 어느 쪽이 맞는지는
정하는 사람이 정할 일이라 손대지 않았다.

## 2. 맥의 "정보" — 이미 아는 것을 보여주지 않았다

영상을 틀어놓고 **정보**를 여는 이유는 해상도와 오디오 트랙을 확인하려는 것이다.
그것은 있었다. 그런데:

**옆에 있는 `.nfo`를 한 번도 읽지 않았다.** `MediaNFOParser`는 라이브러리 로더에만
쓰이고 맥 플레이어에는 아예 등장하지 않는다(`grep`으로 확인). 글레이즈가 직접 써둔
제목·줄거리·포스터가 같은 폴더에 있어도, 정보 패널은 **빈 TMDB 검색 폼**만 보여줬다.
이 영화가 식별된 상태인지 아닌지조차 알 수 없었다.

고친 것:

- `MetadataController`가 영상을 열 때 옆의 `.nfo`와 포스터를 읽는다(`known`)
- 패널에 **작품 정보** 구역: 포스터, 제목, 원제, 연도 · 평점 · 러닝타임 · 장르, 줄거리.
  기록되지 않은 항목은 줄을 만들지 않는다 — 빈약한 `.nfo`가 대시의 행렬이 되지 않도록
- 기술 정보 **다음**, TMDB 검색 **앞**에 둔다. 첫 질문이 "식별되어 있나"이고
  두 번째가 "아니면 식별하자"이므로
- TMDB로 새로 쓰면 그 구역이 새 값으로 갱신된다. 위쪽이 옛 주장을 계속 보여주면 안 되므로
- 두 구역의 이름이 똑같이 "작품 정보"였다. 검색 쪽을 **"TMDB에서 찾기"**로 바꿨다

## 3. 메뉴 구조 — 인스펙터가 메뉴 막대에 없었다

메뉴 막대에는 **파일 › 영상 열기(⌘O)**와 라이선스뿐이었다. 자막·재생목록·정보 세
패널은 **툴바 메뉴를 열어야만** 닿을 수 있었고, 그중 둘은 한 단계 더 안쪽이었다.
키보드로는 아예 닿을 수 없었다.

맥에서 인스펙터는 **보기** 메뉴에 있고 단축키가 있다. 이제 있다:

```
보기 › 자막      ⌘1
     › 재생목록  ⌘2
     › 정보      ⌘3
```

## 확인한 것

- 아이폰 시뮬레이터: 컨트롤이 개별 유리 디스크로, 재생만 크게, 제목은 온전히
- 맥: `.nfo`가 있는 영상을 열고 ⌘3 — **듄 / Dune / 2021 · ★7.8 · 155분 · 공상과학 ·
  모험**과 줄거리가 기술 정보 아래에 나온다
- 보기 메뉴에 세 항목과 단축키

테스트 308개 통과. 맥·애플티비·아이폰 모두 빌드되고, 아이폰 실기기에 설치했다.

## 확인하지 않은 것

- **포스터 썸네일.** 시험한 폴더에 포스터 파일이 없어 텍스트만 확인했다
- TMDB 검색과 쓰기 자체는 여전히 키가 없어 확인하지 못했다
